# 接触后命令保护记忆：当前参考输入的阴性结果

公开794维观测的第773列是“空中且曾触球”的阶段，不是永久触球标志。机器人落地后切换到774列，因此不能只用773列的当前值来维持触球后恢复控制。新恢复增量候选已按实际观测锁存接触，落地后继续生效。

另行检查了原工具净空命令保护器是否也受到这一阶段切换影响。候选只为保护器提供过去真实观测接触的0.4/0.6秒有界记忆，演员、实际794维输入、日志、碰撞、规则和得分保持原样，没有未来接触信号。原保护器仍检查完整工具支撑、夹具和网体高度。

对真实TRAIN0/29/69/100/112/123的4800条公共输入，0.4/0.6秒设置分别在41/107个控制行保留接触记忆，但**所有输出动作与原策略逐位相同**。没有触球前动作变化、腿部变化或源网络变化；最大机械臂目标速率仍为5.000019 rad/s的浮点舍入，原限制5保持。部分reset保持其他lane状态。

这个结果没有证明该记忆修订能够改善当前恢复，也没有证明它在其他轨迹上永远无效。当前不安排该单独候选的GPU试验，继续优先推进已经登记的横向拦截流程和实际恢复动作参考。程序与 `CPU_CONTROLLER_CHECK.json` 保留；未把这项CPU检查作为新原生成绩或验收通过。
