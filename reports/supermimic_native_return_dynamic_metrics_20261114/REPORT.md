# 原生 return 与动态条件恢复统计

本轮仅修改日志与统计，未启动训练或新的 Isaac 原生评估，未改变奖励、物理、动作映射、正式128环境面板及成功判定。
代码提交：`c34280a4fb802994f79b8352eba28bdbba301bb6`。

## 74是否被固定

当前 SuperMimic 正式评估入口原本就以本次128例中实际合格空中拍线触球数量作为条件恢复分母，并没有硬编码74，也不根据历史74个编号选择动作或评价案例。74是初始化策略该次实际结果；此前MPC实验曾使用固定74例作历史回归集合，那些历史记录保留，不据此约束本轮学习指标。

训练与评估现共用动态统计：

`条件恢复率 = 本轮实际合格触球且恢复成功的回合数 / 本轮实际合格触球回合数`

训练每次迭代只统计刚结束的真实回合，并另报当前进程累计结果。没有结束回合或没有合格触球时，相应比率为null，不填0，也不借用上一轮74。正式评估仍是原128环境；合格触球率、球侧合格率及complete5继续以实际评估回合总数为分母。触球数下降可能令条件恢复率上升，必须连同触球率一起看。

## 新增原生return

原生控制步奖励已经包含相应奖励率的dt处理，记录值为完整回合逐步奖励的无折扣和，不再次乘dt或gamma。它不同于想象目标、单步reward均值及critic估计。

- 每条环境独立GPU累加，终止步奖励计入，在reset前写入回合记录，再清零该lane。
- `native_episodes.jsonl`：逐回合 `native_episode_return`、`native_episode_length_steps`、`native_return_definition`，以及原有事件证据。
- `training_history.jsonl`及终端进度：本轮刚结束回合return均值、当前进程累计均值、标准差/范围、实际动态触球和恢复计数。
- `training_status.json`：本进程全部已结束回合汇总。
- `native_partial_episodes.json`：退出时尚未结束的累计return，明确completed=false，不混入完整回合均值。
- 断点恢复重新reset原生环境，因此新进程累计统计从零开始，并明确标注scope；不会伪装为恢复了旧半回合。
- 当前入口未添加TensorBoard writer，以上数据保存在JSON/JSONL及控制台中。

128条逐回合return见 `reconstruction/episodes_with_returns.json`；来源与哈希见 `reconstruction/metrics.json`。800个控制tick采集期间共有128个终止回合；15个lane在提前终止并reset后留下新回合的未完成片段，这些片段不进入上述128回合return。

这些是已有数据的补充统计，不代表本轮策略更新或新性能收益。原数据采集/评分已完成，但历史进程在关闭时发生PhysX析构SIGABRT，不能把历史进程描述为干净退出；本轮CPU还原退出码0。

## 验证与边界

指定CPU测试17通过，退出码0：覆盖终止步计入、异步reset隔离、未结束回合、动态分母、分母为0、缺失事件不得默认False、无二次dt/discount、终端评分透传和原动作合同。语法检查和git diff检查通过。

新增env日志钩子的完整原生集成尚未复跑；本轮验证为CPU模块测试、源码执行顺序核对以及既有原生数据还原。旧策略没有更新，也没有据此宣称学习有效或成功率提高。随后实际训练或评估启动时才能验证新增日志钩子的端到端运行。
