# 用真实出球与早期球位置分析下一步拦截目标

原leg06新8版的全128固定评估仍为0完整/27空中/14恢复/6攻击/NF0。此隔离分支在CPU上分析其中27个真实空中出球，主GPU0的预热7/13更新训练、原资产和原规则均保持。没有新增原生机器人执行。

先从实际碰撞记录的球心位置和出球速度，复算重力、原二次阻力、5.2g/半径25mm球替身的自由飞行。在23个具备可核对首次落点、没有后续球网/身体碰撞的案例上，最大三维首落误差17.18mm，符合事前20mm检查门槛；最大各轴误差为X0.753mm、Y17.166mm、Z0.240mm。4个未具备自由飞行落点核验条件的原失败保留，没有删除评测难例。实际过网末沿的最大X/Y/Z误差为0.000024mm/7.905mm/0.276mm。该模型是规划近似，原生事件仍是最终证据。

规划采用原64段4mm厚悬挂网体和网柱、有限球半径、原网顶和网宽判据，以及两采样端点之间的速度步长缓冲。它寻找不碰网的保守子集；原规则允许的合法擦网回球没有因此被取消。初版CPU模块补齐了网下/绕端的排除，新增两项必要负例后共5项CPU检查通过；原V1源码起点7900890、结果及修订记录保留。V2重新执行同27个实际出球，结果数量保持。

在每个实际触球位置保持实际速度大小，低于8的仅假设提高到8米每秒，27个点中17个找到规划候选；该假设不证明机器人能生成该速度。候选俯角约17.7到21.4度向下，首落X约3.79到3.95米，有限网体缓冲间隙约7.5到27.8mm。全部17个所选候选用62.5微秒重新积分，未改变原生完整成绩。

再单独把假定出球速度固定为8.01米每秒，使用实际记录的更早50Hz球位置进行时序敏感性分析：

| 假定出球起点 | 相对真实触球的提前时间 | 27点中有CPU规划候选的数量 |
|---|---:|---:|
| 实际触球位置 | 0 | 18 |
| 最后一个实际早期球样本 | 6.6–24.9ms，中位15.9ms | 25 |
| 再前一个实际球样本 | 26.6–44.9ms，中位35.9ms | 27 |

这些起点来自实际记录，没有重新执行那一时刻的球拍碰撞。所有所选方向再次以原生62.5微秒步长检查，粗细积分首落差最大0.000000338米。对应更早两个时刻，原动作拍头前侧中心距球的中位距离分别0.204米和0.400米：不能把几何候选当作机器人已经可达，也不能通过瞬移拍头来实现它。下一步需要从地面重新规划预置姿态、站位、起跳时机和拍面方向，再用原质量/关节限制进行原生验证；在线actor仍只能使用因果公共观测。
