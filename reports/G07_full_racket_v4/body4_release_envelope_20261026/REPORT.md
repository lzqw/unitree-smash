# body4实测释放后的方向诊断

原固定128仍是1完整、59空中、30合格恢复、8攻击、NF0。此次只分析这些实际执行结果，没有启动新机器人作业，也没有读取正式A/B。

59个合法空中拍线回合全部有唯一首拍事件，其实际球心位置与原生出球速度保留。37条单次接触、已记录首次落地且没有球触网/身体碰球的自由段用于核验：同一已声明气动参数RK4首落最大误差9.601毫米，低于事先登记20毫米容差；其他回合仍保留在原128评分中。

在实际球心位置不变、速度模至少8米/秒(原模低于8时仅假设提高到8)、水平朝原目标中心的限定俯仰网格中，29/59找到保守的无碰网、攻击与目标落点方向样本。所选29条又以62.5微秒细化积分核对。其余30条是该网格没有找到，不是数学不可行、不是速度可实现性或完整成功率上界。保守净空屏蔽只用于规划，不排除原生规则允许的合法触网越网。

找到方向样本的实际球心高度中位数1.7573米，未找到组为1.7004米；只是条件描述，不能用来宣称提升高度必然成功。真实完整TRAIN36也有方向样本，实际出球8.029874米/秒、首落[3.868195,-.592098]米、恢复3.458932秒；CPU提出另一方向并未由机器人执行。

这说明后续还需同时改善有效接触位置/速度及恢复，不能把只改出球方向当作已解决跳跃扣杀。当前原生16候选全局平面/法向/增益测试继续，48更新学习队列待它的完整固定评估选源；没有因这份CPU分析修改main输入。main396来源加PLAN共397项在分析前后逐项保持。
