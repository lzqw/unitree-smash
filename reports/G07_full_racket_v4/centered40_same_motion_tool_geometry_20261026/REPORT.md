# 同一批真实运动中的工具中心几何对照

已完成40版原全TRAIN128中的49110个有效50Hz姿态表明：把旧短拍板中心与完整球拍拍线中心放到同一批实际法兰姿态上，在各回合已观察到的完整球拍中心最高姿态处，高度差中位数为0.24051米，范围0.20136至0.25882米。这量化了装配几何带来的作用，不是旧质量机器人重新执行的成绩，也不是动态可达高度极限。

| 比较量 | 最小 | 中位 | 最大 |
| --- | ---: | ---: | ---: |
| 实际完整球拍中心的各回合已观察峰值高度（米） | 1.56328 | 1.68589 | 1.72663 |
| 同一峰值姿态的旧短拍板中心高度，CPU几何（米） | 1.35607 | 1.44360 | 1.48894 |
| 逐回合同姿态中心高度差（米） | 0.20136 | 0.24051 | 0.25882 |
| 22次合法空中拍线接触时，同姿态中心高度差（米） | 0.21868 | 0.24038 | 0.25789 |
| 上述接触时，同一法兰速度下中心速度模长之差（米/秒） | −0.13874 | 0.06463 | 0.70864 |

两个中心的法兰坐标直接来自已有装配配置：旧 `[0.18,0,0]`，新 `[0.45,0,0.04]`，质量分别0.09和0.153千克。新球拍的远端结构、不同的转轴投影与法兰平移共同决定点速度；不能把杠杆长度比直接当成实际速度比。表中速度差为中心点比较，实际离中心接触点的速度另行计算；两者都不是羽毛球出球速度。

源40版的22次合法空中拍线接触实际x为0.80115至1.03807米，z为1.62098至1.76860米，位于原1.5米网平面的己方。实际接触点速度0.31118至1.78663米/秒，中位0.85500。全部73次实际接触均用 `v_hit = v_flange + omega_flange × (p_hit − p_flange)` 重新核对，最大误差2.82e−5米/秒。由法兰姿态重建拍线中心与原生拍线中心的49110个位置比较，最大误差1.64e−5米。

所有128例峰值及全部73次接触的逐项结果保存在 `ALL128_OBSERVED_POSE_PEAKS.csv` 和 `ALL_ACTUAL_CONTACT_POINTS.csv`，计算与所有来源SHA见 `build.py`、`REPORT.json`。原全128回合仍为0完整、22空中、10条件恢复、NF0；新075训练没有贡献本报告成绩。原始40版全身/球轨迹及接触记录在[已验证的137MB附包](https://github.com/lzqw/unitree-smash/releases/download/g07-full-racket-v4-progress-20261024/G07_centered8_to40_frozen_TRAIN128_video_and_diagnostics_20261026.zip)中。

本分析的范围：50Hz采样峰值可能低于连续时间峰值；旧中心在新球拍实际运动上的位置与速度是CPU运动学反事实，没有重新模拟旧质量/惯量、碰撞、控制响应或恢复。新旧真实合法击球和恢复成绩仍按各自历史任务分开，历史对照见 `../current_legacy_comparison_20261026/REPORT.json`。本报告不支持新球拍已达到原正式门槛、旧机器人会发生同一接触、或质量变化的因果性能结论。
