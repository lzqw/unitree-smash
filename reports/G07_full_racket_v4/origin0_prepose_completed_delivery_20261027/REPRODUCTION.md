# Origin0 prepose8 completed search and cold128

This package preserves all eight sequential128-case searches and the separate frozen128-case evaluation. Cold measurements are0 complete,4 airborne contacts,0 qualified recovery,0 attack, numerical failures0. No formal A/B evaluation has run and the original50/70/85 goals remain unmet. Four cold contacts all have body landing; the search TRAIN100 recovery flag is not inherited by the cold episode.

`search8/source_snapshot.zip` and `cold128/source_snapshot.zip` contain the actual producer source with its hashes and dirty patch. `search8/INPUTS.json` pins the actual source policy, overrides and original TRAIN suite. `coordinator/SEARCH_RECEIPT.json` contains the completed1024-row and actual public-action replay checks. `search8/best_candidate.pt` includes both original learned source layers and the selected runtime overrides; do not substitute an old-origin16 score.

The exact original commands, seeds, bounds and observed resource charges are in each `job.json`. Use the pinned Python/Isaac environment, restore the original directory layout and full assets, inspect both source snapshots and original case hashes, and run the recorded commands with fresh output directories. Restoring these files or CPU replaying a command stream is not proof of a new Native physics result. PhysX contact caches and floating-point execution prevent a promise of bitwise rerun results.

The full robot/racket USD/mesh runtime companion is [G07_placement075_stage8_to40_completed_native_and_frozen_TRAIN128_20261026.zip](https://github.com/lzqw/unitree-smash/releases/download/g07-full-racket-v4-progress-20261024/G07_placement075_stage8_to40_completed_native_and_frozen_TRAIN128_20261026.zip), SHA256 `44528da938ad422ed6a5515a32c65df3b763421288d2b4ff6f9236ab36c517bb`. External pinned IsaacLab/IsaacSim/Torch and recorded absolute USD/walking model dependencies are still required. This package is not a standalone simulator installation.

`video/` contains the actual cold run's four airborne contacts (TRAIN69,100,112,123) and original TRAIN0 miss, including whole8-second episodes, repeated-frame slow motion, actual contact substeps and first-landing events. Last-pose freezes explicitly use the final50Hz sample. `video_evidence/` contains preparation, all128-row and command checks, full decoding and visual review. Motion is recorded execution; no new Native job was launched to manufacture footage.

The original full128 arrays are in `cold128/all_first_episodes.npz`. To rebuild the renderer snapshots, restore their recorded source paths and run `video_evidence/prepare.py` from the main repository after adjusting only its report-location resolution in a new, audited copy. It also checks the current source custody; that historical process condition must be interpreted from its archived completion receipt rather than forging a live owner. The renderer itself accepts a fresh `--snapshot` and `--output`. Its optional `moderngl5.12.0` and `glcontext3.0.0` dependencies were loaded from `/tmp/unitree_video_deps`, with CUDA disabled and Mesa llvmpipe. Native and video source paths are recorded to make relocation limits explicit.

The independently admitted next gain/body search remains a separate live experiment. `next_method_admission/` describes its actual cold source and command-level checks; it does not assert that the new method improves performance.
