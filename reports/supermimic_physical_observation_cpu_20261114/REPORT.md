# 物理状态重建观测：独立实现与CPU证据

日期：2026-11-14。基于fd4585a开发。此模块尚未接入训练或当前原生评估。

## 实现

新增 `quadsmash/rl/supermimic_physical_observation_v1.py`：

- 保持原794维actor输入和全部关节顺序。将根位置/姿态/速度、18关节位置/速度、球状态、接触/事件、任务目标、实际最终命令作为显式输入。
- 拍面位置和法向由锁定URDF运动学计算；拍面相对线速度和角速度由关节速度及Jacobian计算，不能被预测网络分别任意改写。
- 重力由姿态计算；历史只插入一帧，其余顺移。阶段由原接触与飞行事件逻辑生成；球可见性、目标开关、时钟、最终命令使用原语义。
- 纯函数不原地修改历史或分支输入，保留经关节到拍面的可微梯度。
- 提供只读原生状态提取入口，核验18关节名称并复制数据；不step/reset，不修改执行器或控制器记忆。

## 限制与后续门槛

- 目前只是观测重建器，不是已经完成的物理世界模型。网络仍需预测紧凑物理状态及受监督接触变化。
- 原生接触/飞行阶段采用布尔逻辑；想象中的平滑事件代理和梯度语义尚未设计，不应直接硬阈值接入actor BPTT后宣称事件梯度成立。
- 基础控制、残差混合器、机械臂限速等执行记忆及任务奖励锁存还需完整保存和逐节点推进；当前输入不能被宣称为完整Markov状态。
- 没有改变BPTT/GAE、奖励、时域、物理、成功定义、当前评估或加载策略。
- 没有训练更新，没有新的任务成绩。应在初始化能力复验完成后继续完成物理状态/执行接口，不直接用此CPU通过开放actor训练。
