# G06：真实羽毛球空中接触并恢复（已通过）

G06 从 `artifacts/G05/policy.pt` 初始化，使用真实 Isaac Lab / PhysX `RigidObject` 羽毛球，在地面起始状态运行神经策略。训练采用真实物理教师轨迹、行为克隆和 DAgger；教师只提供训练标签，正式评测没有教师前缀、空中重置或状态传送。

来球初始状态固定为 `(7.4, 0, 1.15) m`、线速度 `(-6.0, 0, 6.235) m/s`，命令目标为 G05 已验证的球拍接触面板 `(0.243, 0.001, 0.553) m`、法向 `(-0.525, 0, -0.851)`、目标时刻 `1.48 s`。球的运动、球拍接触、摩擦和反弹均由原生 PhysX 计算；程序没有修正球位姿，也没有注入隐藏冲量。

独立正式评测从地面重置运行 400 回合、64 个并行环境。结果为：400/400 地面初始化，400/400 发生空中球拍接触，306/400 接触后恢复到目标地面区域，恢复率 **76.5%**，数值失败 **0**。每回合接触计数为 1，扫掠检查未命中和未解析均为 0。诊断字段记录了 231/400 回合发生额外的机器人身体接触；这没有被伪装成成功，也没有计入数值失败，球拍接触和恢复指标仍按正式协议计算。

本轮正式评测使用 `physics_dt=0.00025 s`，这是 G02 原生 PhysX 步长夹具中已验证的预算配置，并在评测清单中明确记录。为提高吞吐，机器人跳跃指标每 16 个物理帧采样一次，时间增量按实际物理帧数累计；碰撞响应仍逐物理子步执行，球接近球拍时仍执行逐帧扫掠审计。这是指标采样优化，不改变动力学或接触响应。

正式发布策略为 `artifacts/G06/policy.pt`，证据来自 `reports/G06/eval_formal01`，完整回合数据在 `reports/G06/episodes.csv`。G06 门槛已满足；G07 完整扣杀仍待进行。此前高跳能力搜索的可重复质心上升约 14.2 cm，20 cm 以上尚未宣称达成。
