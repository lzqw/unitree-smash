# Approach-only 阶段一实验配置

以 PhysX 中的完整回球为主指标。合格空中拍线触球后，羽毛球须向前以至少 4.5 m/s 出球，遵守击球规则，实际越网并落入目标区。环境继续维护碰后状态，并在选定 lane 保留 1 秒的恢复尾段。[球侧评分配置](../../configs/evaluation_protocol_v4_approach_ball_only.json)

| 项目 | 实际登记设置 |
|---|---|
| Actor 预算 | Approach 256 次有效更新，Recovery 0 次，每块 8 次有效更新 |
| 提案预算 | 全阶段 512 次，32 个训练块各最多 16 次 |
| 可训练动作 | Approach 保留 18 维，基础策略、Recovery、观测归一化冻结 |
| 原生与想象 | 128 个原生环境，每次提案抽取 16 个有效起点，按接触和随挥事件选择长度 |
| 物理时间 | 控制周期 10 ms，每个周期含 160 个 62.5 μs 的物理子步 |
| 原生采集 | 每次冷启动首块 512 个控制周期，后续块 128 个，保留同一进程内的连续环境 |
| WM 刷新 | 每块 16 次世界模型更新，接触监督请求 32 批，实际有效批数见训练日志 |
| 单次执行变化预算 | 执行归一化命令变化上限 0.02，最终关节目标变化上限 0.08 rad |
| 随机种子 | 原生训练与固定 128 例复评使用 882072，训练续接恢复检查点的随机状态 |

E0 保留原机械臂门控和历史拍速参考。E1 使用 0.25 秒的提前机械臂门控和相对拍面速度目标。两组从同一 Actor、WM 和公共离线数据开始，各自维护在线轨迹及优化器。球侧优先提案规则比较相同起点、冻结 WM 和参考下的候选，要求保留基准已预测出球并保护其球侧损失。[同预算 A8 与身份摘要](A08_MATCHED_CONTROL.md)

开发评估使用固定 128 个发球案例，保持相同初态、球侧规则、资产、执行器和物理时间。主线先完成 A32、A64，E0 同预算推进到 A64，E1 再完成 A128 与 A256。最终用开发案例选定检查点，使用独立 512 个案例与同门控的 E1 A0 进行一次配对。WM 留出轨迹用于模型误差审计，训练侧速度校准只从训练 lane 拟合。

已核对 TRAIN128、固定开发 128 例和最终独立 512 例。三个名单两两没有重复案例 ID，六维发球位置与速度按各分量保留六位小数比较也无重复。E0 同预算 A8 和 E1 修订 A8、A16、A32、A64 首块已归档的在线结算均只包含 TRAIN128 的案例 ID。此次核对仅使用发球清单和现有训练记录，独立 512 例的原生评分尚未启动。
