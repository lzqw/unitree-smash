# Teacher-only joint evaluation upload

This directory contains the executable teacher-only entrypoint, frozen controller configuration, candidate manifest, concise metrics, process/cgroup exit evidence, and reports for the one native evaluation on 2026-11-16.

The raw native trace is intentionally kept on the evaluation host because it is over 500 MiB and contains large binary/contact arrays. Its local path and hashes are recorded in `CANDIDATE_MANIFEST.json` and `TEACHER_DIAGNOSTICS.json`.

This upload contains no SuperMimic source, weights, replay, or training artifacts.
