# Unitree Go2 asset adapter

This directory is the legal asset boundary for the Go2 model. The repository
does not redistribute a Unitree USD or URDF. Put an authorized asset under this
directory and record its source, checksum, license, joint order, limits, mass,
center of mass, inertia, and Isaac Lab version in `asset_manifest.json`.

The current numerical tests use the fixed 18 degree of freedom control
contract. The official Go2 joint names must be mapped explicitly before a USD
scene is accepted.
