# 学生先提出动作，MPC后纠正：实际偏离状态的数据采集入口

2026年11月7日14:36（北京时间）。当前全18关节共同优化的原生试验仍在GPU0运行，已记录300/800控制步，进程4119799存活，尚无最终成绩。下面的新入口已实现、检查并排队，**还没有原生执行结果**。

## 为什么需要这一项

[新版学生评测](landing_event_recovery_student24_20261107.md)在关闭额外教师时为24/128：救回TRAIN58、61，却丢失5个旧成功。42条成功示范的击球前缀和恢复头初始输入已核对一致；随后身体状态偏离，再出现较大的动作修正。仅在固定示范物理观测上递推网络上一命令，没有复现同等幅度的放大。

因此下一项学习数据应覆盖**学生实际到达的状态**。不能把原示范同一时刻的动作直接贴到已不同的身体状态上，也不能继续以训练MSE下降作为恢复能力提高的证据。

当前控制辅助最佳仍35/128，两次固定面板复现；原学生基线仍27/128。新采集入口不会自动替换它们。

## 单一最终动作入口

执行次序明确为：

```text
冻结原策略和基础控制提出基础位置命令
    → 冻结学习恢复头提出学生命令
    → 持续MPC读取这个学生命令和原生状态
    → 在原控制接口中保留或纠正
    → 只执行最终命令
    → 双方下一步使用这个实际最终命令的历史
```

此前评估入口把MPC放在基础控制返回动作之前，而学习头在其后执行；同时它明确禁止二者一起开启。新模式并非移除这个检查后直接叠加：控制请求与MPC过滤已拆成两个调用，学习头在它们之间运行，教师输出后不会再被学习头覆盖。

原基础请求和MPC过滤代码通过AST哈希核对保持原逻辑；新增的只是在声明模式下调整调用顺序，并以学习恢复头的因果资格屏蔽未到恢复阶段的环境。原教师关闭评估及旧控制路径默认不变。正在运行的评估源码没有被修改，新补丁仅允许在当前作业和审计退出后安装。

## 本轮声明的范围

下一项作业使用已测24/128的冻结学习头，以及35/128试验的命令历史控制实现。7个关键控制/建模文件与35原生源快照逐一哈希相同，但新学生请求和新到达状态不同，不能继承35的性能结论。

全部128例进入同一因果判据：观察到空中触球，随后进入足端支撑阶段，恢复资格保持到回合重置。它没有已知失败案例名单，不把未来落点或恢复结果用于触发；观察到拍框等接触也不自动等于合格拍线触球。

首轮仍是资格建立后持续辅助到回合结束，**不是已经实现预测风险选择、稳定后交还或教师依赖下降**。当前任务优先确认持续恢复能力；这些进一步功能仍属于完整目标的待完成部分。

原机械臂负载、球拍、摩擦、力矩/速度/关节范围、目标变化率、5 m/s及恢复判定不变。不混合已求出的动作与学生动作，也不启用额外力矩overlay。

## 记录与坐标

每个控制步保留原始公开观测及：

- `base_command`：冻结原策略及基础控制的实际请求。
- `student_command`：学习恢复头提出的请求。
- `previous_command`：上一条实际最终执行命令。
- `final_command`：本步真实下发命令。
- 学习头输出、教师修改量、因果资格、首回合标记。
- MPC的学生请求、求解/首步/终端状态、最终目标和真实物理回合结果。

这是一条确定性采集路径，**没有学生随机采样的log_prob，也不是PPO的on-policy rollout缓存**。不能伪造概率信息或将教师动作冒充采样动作。

坐标还有一个重要区别：若以后训练一个替换当前恢复头的新网络，总标签应相对原`base_command`计算。`final_command - student_command`只是教师的新增修改，不是替换头的完整输出。两种请求分别记录，防止把教师增量误当作全部残差。

本轮结束先做动作及结果审计，不自动生成正向示范、不自动训练或推广模型。失败纠正不能成为正向标签；完整成功与仅恢复成功要分开。采用的18维原生目标坐标也不能冒称原先固定尺度的残差坐标。

## 验证与下一条实际作业

5项接口测试通过，覆盖：学生只提出一次动作、教师后置、实际最终历史回写、非恢复环境不可修改、原机械臂命令变化率及回合重置。实际评估器AST检查也已运行：验证旧请求/过滤逻辑哈希，执行真实调度代码片段，检查新模式的显式准入条件。这里只用数值接口检查，未把测试控制器当成物理仿真。

新原生审计程序会独立重放学生请求，核对它与MPC收到的请求一致，再核对最终下发和真实历史。它已验证会拒绝旧的教师关闭结果；**新辅助采集是否通过该审计，必须等实际运行后才知道**。

输出比较包括：与同一24学生无教师的差异、原27成功保留/丢失/新增，以及与预选26案例的35控制辅助结果的区别。后一个对照同时改变了学生和覆盖范围，不能仅由总分差作单因素归因。
