# 用球拍避网方向改进整段恢复搜索

2026-11-09。接续[三个参考衔接案例的失败结果](pure_control_native_head_failure_analysis_20261109.md)：474个粗候选和9个细模型候选都未完成恢复，9个细模型候选首先失败于球拍碰网。当前原生落地成绩不变，没有启动RL、BC或蒸馏。

## 本轮改变

仍从原生V20的10:320、55:317、82:323实际状态出发，规划完整18关节动作直到8秒。使用上一轮失败轨迹中碰网前6和12步的几何状态，计算球拍到实际网带的距离梯度，生成朝远离网面方向的收拍初值，再进行全身搜索。失败轨迹只作搜索初值，不是成功参考或专家标签。

球网检查来自原有网带、网柱和机器人碰撞几何，未改成无限平面；也没有删除网或放宽穿透要求。每个状态的两个梯度均以18关节中央差分独立核对，最大误差约1.99e−6米/弧度。数值核对容差是.002米/弧度，有限差分步长1e−5弧度，仅用于导数检查，不改变碰撞判定。

初值尝试3、8、15、30厘米的局部几何距离增量，并比较从首条命令开始调整或在前0.1秒逐渐调整。它们只是产生不同初始猜测的参数，不保证实际拍头位移，也不是新的动作或硬件权限。此后全部18关节、包括首条命令都参与搜索，不冻结腿部、不把机械臂固定回零。

每个候选仍经过原执行器、耦合动力学、接触、脚间干涉及碰撞检查；完整路径与原末端稳定优先。使用16子步搜索、160子步复核。静态梯度不能证明动态可执行性，最终仍需真实原生执行。

## 运行与边界

新程序已启动：8个CPU进程，2400秒内部期限，其中800秒留给细模型复核；2600秒外层保护。81项输入和源码哈希固定，每个状态17个初始猜测。当前尚无最终结果，未加入原生参考库、未生成教师数据；GPU0既有原生作业及队列保持。

本轮属于离线整段规划改进，不是已实现实时序列MPC。若找到可行路径，还须经状态反馈以及从地面执行冻结前缀的完整Isaac评估，不能用梯度正确或模型通过代替落地成功。
