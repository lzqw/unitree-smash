# 原生命令的一步预测审计与持续恢复进度

本轮完成了18个实际原生转移的一步重放，未获得新的完整原生成绩。学生系统仍保留27/128基线；运行中的持续恢复MPC不能提前算作新增成功。关键发现是：细化积分改善了机械臂预测，但左前髋误差与后足支撑预测差异仍存在，不能仅靠接触滞回来解释或消除。

## 实际执行的审计

使用已完成原生V1的TRAIN3第460—477步，每次从该步实测全身q/v、接触状态与上一条实际命令重新开始，预测下一控制步。输入是原生程序最终下发的float32关节目标，不是优化器未执行的理想命令。分别使用16与160个积分子步，控制周期均0.01秒；160子步与本机原生物理步长一致，但不意味着碰撞求解器等价。

基座速度先变换到世界坐标再比较。接触诊断额外记录模型冲量、法向力与足端间隙，未修改预测器、物理参数、接触阈值或任何排队控制器。18个一步预测每步都重新使用实测状态，不是连续0.18秒预测，更不是完整落地验证。

| 误差／诊断 | 16子步 | 160子步 |
|---|---:|---:|
| 左前髋速度RMSE（rad/s） | 0.08849 | 0.08633 |
| 最大关节速度误差（rad/s） | 0.29110 | 0.28897 |
| 机械臂joint2速度RMSE（rad/s） | 0.01076 | 0.00562 |
| 基座世界线速度分量RMSE（m/s） | 0.000577 | 0.000551 |
| 基座世界角速度分量RMSE（rad/s） | 0.004099 | 0.003083 |
| 相同法向力滞回定义下的接触差异 | 9/72足次 | 8/72足次 |

最大左前髋偏差发生在首步。多项机械臂误差随积分细化降低，左前髋偏差基本保持。因此，“全部误差来自粗积分”不符合这批数据；同样，基座一步误差较小，不能把整个预测模型描述为完全失真。当前样本只覆盖单个案例的短区间，不代表其他落地状态。

## 接触力口径更正

本机安装版本的`ContactSensorData.net_forces_w`明确为**法向接触力**；不能因为记录的XY分量为零，就推断真实足地没有摩擦。该语义也见[Isaac Lab 2.2.1文档](https://isaac-sim.github.io/IsaacLab/v2.2.1/source/api/lab/isaaclab.sensors.html)。其他版本或后端需另行检查，不能直接套用最新主分支文档。

初版审计曾用模型总接触力范数计算观测滞回。已保留原源码快照、原结果与更正记录，并用模型法向力重跑。状态预测不变；本批接触差异计数恰好也不变。正式比较使用法向力的1 N进入、0.5 N保持阈值，原生传感器与控制逻辑均未改动。

160子步中的8次差异均涉及左后足：模型认为有接触／支撑，原生下一采样时刻的法向力为零。例如第460步预测下一步左后足约8.85 N，原生采样为0；第467步约27.88 N，原生仍为0。

这些状态的足端离地间隙很小，但这**不能证明该足整个区间从未接触，也不能证明模型一定可以向它加载**。当前原生记录是采样力，模型还保存了区间冲量，两者不是同一个测量量。需要后续核对微步接触时序、接触建立与实际负载变化，不能以零XY、单次力阈值或球面间隙代替结论。

## 对优化方向的影响

1. **持续反馈优先。** 已排队的方法从实际状态更新支撑动作，测试原恢复参考与机械臂速度余量候选；不把保持单帧目标当成持续恢复。
2. **数值精度与支撑模型分开检查。** 精细积分可改善机械臂预测；左前腿首步偏差和左后足加载差异需要实际接触／响应证据，不能继续只扫描滞回阈值。
3. **保留模型约束与实际验收。** 候选仍须通过原路径、终端检查及最终非线性复核，完整回合还须检查真实稳定窗口、非足部接触、球侧条件与旧成功保留。
4. **暂不蒸馏未验证动作。** 只有原生执行证实有效、接口一致的纠正才进入正向学习。模型可行、数值故障零或中间未倒地均不够。

## 后续对照：直接删除轻载足接触并不是已证实的修正

继续对同18个原生转移做了一个离线反事实诊断：只从模型接触Jacobian中移除左后足，重新求解完整耦合动力学、其余足冲量与隐式PD；其余输入保持一致，仍用160子步。这个模型允许该足穿地，仅用于定位误差，**不可作为可行教师，也未改动任何原生控制器**。

对8个“原生下一采样法向力为零、模型下一法向力大于0.5 N”的步骤：

| 速度误差RMSE（rad/s） | 原完整接触模型 | 整步移除左后足接触 |
|---|---:|---:|
| 左前髋 | 0.12563 | 0.13242 |
| 左后大腿关节 | 0.06100 | 1.54168 |

首步左前髋误差从−0.28897变为−0.29733 rad/s，并未被消除；左后腿预测反而明显变差，部分步骤还穿地。第464步局部误差有所改善，因此也不能将结论扩展成“删除接触在任何状态都更差”。

这个对照不支持将采样力为零直接变成“整个下一步禁止建立接触”。它没有证明原接触模型正确，更不能据此反推原生每个微步的真实接触史。接下来需要连续微步的原生受力／运动证据，而不是依据单次力采样改写支撑集合。强制删除接触后的标签一致性是人为结果，程序刻意不把它作为改善指标。

同时复核已保存的原生参数准入：关节armature、关节摩擦均为零，驱动kp/kd、力矩／速度限制与模型设置一致；足地材料组合系数约0.65。因而本批误差不能简单归因于“漏了一个已记录的非零armature”或“摩擦系数随意设置”。这仍不排除PhysX接触求解、驱动迭代及其他离散模型差异。
