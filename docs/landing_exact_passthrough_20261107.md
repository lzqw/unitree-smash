# 恢复MPC：未修改学生命令的精确直通

2026-11-07。已完成真实记录回放与代码检查，原生效果尚待评测。

## 从20/128失败里发现了什么

对原27学生＋全128因果教师的13个丢失案例，比较首次命令变化后的200毫秒。10例在此窗口内教师与当时学生请求的差别只在现有映射检查容差5e-6 rad以下，典型约3e-7 rad。这说明不能将全部失败解释为初始大幅修改学生动作；它也不证明微小变化就是全部失败的唯一原因，后续QP动作和并行物理差异仍可能参与。

原生入口在QP求解前无条件执行：归一化学生动作→关节目标→限幅/限速→归一化动作。即使限幅/限速没有改变任何目标，浮点往返也会改变命令位值。求解失败时这些变化仍作为学生回退执行。

对40036条真实控制记录逐条重算原接纳范围：全部40036条均无需额外裁剪，但旧往返全部改变了至少一个命令位值；其中15478条没有应用QP首步。离线回放不改变已发生的轨迹，也不证明删除往返就一定提高成功率。

## 修正内容

保留原目标接纳与物理限制，只对接纳过程真正修改的关节重新编码。未修改的关节直接保留学生原始float32命令；有实际限速或限幅时仍执行原裁剪结果；接受教师纠正时仍走原教师输出路径。没有按误差大小忽略真实裁剪，也没有改变QP可行性条件。

2项数值测试覆盖无需裁剪时逐位保持，以及仅两个手臂关节被裁剪时其他16关节不变。40036条实际状态回放通过：最终目标对接纳目标误差上界3.38e-7 rad，在原5e-6 rad映射容差内，原关节界限与手臂目标限速均未放宽。

代码：`quadsmash/control/exact_command_passthrough_v1.py`。独立原生入口补丁：`scripts/patches/exact_student_passthrough_entry_v1.patch`，尚未安装到当前运行任务。
