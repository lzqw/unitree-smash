# 实际命令的一步预测：局部误差已量化，接触尾部仍有明显偏差

2026-11-09，纯控制诊断。使用已完成的58／123原生恢复分支，选择30、42、58、123四个案例；本次没有新增原生仿真、训练或修改控制参数。

## 做了什么

从717个实际控制边界读取完整q、v、足端受力和上一命令，使用下一边界记录的环境目标回核本步最终下发目标，再预测10毫秒后的状态。分别使用16与160子步，共1434次预测，全部完成，耗时72.46秒。原生初态和原生轨迹没有被改写或传送。

目标回核读取的是环境传给原执行器的位置目标，不是PhysX隐式驱动内部力矩。预测器包含现有全身模型、隐式位置PD近似、足地摩擦与已建模的内部接触；不据此宣称复刻了全部PhysX接触缓存或碰撞。

采样包括均匀间隔，以及接触切换、参考退出和稳定窗口丢失附近；限定在首次原生非足部受力之前的控制区间。因此是四例有目的采样，不能当成独立随机试验或全状态模型精度。

不能用位置误差很小掩盖速度尾部误差，也不能因一次10毫秒预测准确就认定数秒恢复可行。细化子步没有一致降低所有最坏误差。

尤其要分开新恢复前后：123的2.009 rad/s最大误差在tick313发生，早于新恢复参考在tick409被选择。只统计选择新参考后的144个采样间隔，其160子步最大关节速度误差为0.153 rad/s，最大根角速度误差0.00468 rad/s。58的新参考后140个间隔相应为0.466和0.02570。不能把123早期误差归因于新恢复反馈。

42最大误差在tick728，伴随实际接触标志从三足变为一足；模型同时预测左前小腿触地，而原生随后记录左前大腿触地。这个观测定位了接触边界附近的偏差，但没有唯一证明是接触几何、隐式驱动、内部碰撞还是其他因素。模型未完整处理所有非足部碰撞响应，不能用该点宣称PD参数已校准或机械故障。

## 对下一步的影响

当前证据不支持继续笼统地把所有失败归因于“位置接口完全执行不出来”；新救回两例在多数采样处具有较小局部误差，实际闭环也完成了落地。但是，局部预测可用仍不等于存在合适的长程恢复动作，42仍会在持续支撑中失败。

因此保持正在运行的V15支撑基底＋四条恢复方案组合实验，先检查能否保留42并同时救回其他案例，不因本次误差统计直接改硬件参数或全局提高增益。对接触附近的误差继续单列，后续序列规划仍须接受原生全回合检验。
