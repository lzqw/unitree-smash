## 当前证据

已完成的持续支撑与接触实验仍为 `27/128`：

- 连续参考、触地后强制求解、力矩 overlay、首步保持：均未增加完整成功；
- 5 N 接入、1 N 卸载、连续 3 tick 释放的接触滞回实验：`27/128`、74 次合格空中触球、34 次条件恢复；
- 历史单次 `28/128` 是触地后定高捕获近似的辅助执行结果，不能当作学生已经学会，也不能当作真实 VHSIP 的稳定收益。

当前基线的任务漏斗应写成交叉统计，而不是把所有计数当成嵌套层级：

```text
128 回合
  ├─ 74 合格空中拍线触球
  ├─ 53 满足除恢复外全部球侧条件
  ├─ 34 条件恢复合格
  └─ 27 同时满足完整事件链
```

因此恢复控制直接针对的仍是约 26 个“球已打好但恢复未通过”的回合；其余失败主要发生在接近、拍线对准、出球和落点环节。

## 本次已修正的两个关键一致性问题

### 1. V2 终端验收不再使用第二条预测路径

以前 V2 重新从初态调用 `_integrate(state, acceleration)`，没有传入执行器计划，也没有调用预测接触转换。现在 `LandingSupportMPCV1.replay_horizon()` 统一重放：

```text
每个阶段的加速度 + PD 目标/力矩
    -> 执行器回放
    -> 预测接触转换
    -> 下一阶段状态
```

终端支撑裕度检查与生成候选动作使用同一条轨迹，避免“规划用一套模型、验收用另一套模型”。

### 2. 执行器回放增加整机动力学一致重算

旧实现只按 `realized_torque / requested_torque` 缩放关节加速度，浮动基座和接触力仍来自旧 QP。现在默认在 `executor_replay=True` 时，用实际隐式 PD 力矩重新求解：

\[
M a + h - S\tau - J^T f = 0,
\qquad
J a = -Jv/\tau_c - \dot Jv.
\]

这会同时更新浮动基座、关节和当前接触约束下的预测加速度。若 KKT 系统非有限或残差过大，才回退到旧的保守关节缩放，并在代码中明确这只是 fallback。它仍不是 PhysX 冲量模型，不能宣称等价于原生力矩 WBC。

## 接触状态机

新增 `TouchdownContactStateV1`：

- 足端几何/碰撞观测消失时立即释放；
- 世界 Z 向受力达到 5 N 才接入；
- 已接入后低于 1 N 连续 3 个实际控制 tick 才释放。

这里的原始“几何接触”字段实际来自足端接触力范数的 1/0.5 N 滞回，因此报告应称为“接触观测标志”，不能把它当成独立几何真值。滞回只减少模式抖动，不等于已经形成有效恢复动作。

## 为什么 MPC 仍没有自动提高成功率

1. **接触事件仍是近似的。** 预测触地主要修改接触集合，没有碰撞冲量、速度跳变和接触顺应性。
2. **位置-PD接口不是无损力矩接口。** QP 规划的总力矩会经过位置限速、PD、饱和和 PhysX 隐式执行。
3. **恢复需要持续反馈。** 固定一帧目标保持数百毫秒，不等于依据实际支撑、质心和角速度滚动更新。
4. **MPC 只影响恢复失败子集。** 54 个未形成合格拍线触球、21 个其他球侧失败，不能由落地 MPC 直接解决。
5. **接触识别与承重能力不是同一个状态。** 当前受力低不一定代表永远不能加载；反之，当前受力高也不代表下一步仍可持续支撑。

## 接下来采用的控制结构

```text
实际状态和足端受力
    -> 接触状态机（接入/卸载/重新落脚）
    -> 统一的执行器-aware 短滚动预测
    -> 支撑 QP / 有限接触模式候选
    -> 触地后连续参考与质心/姿态反馈
    -> 统一动作仲裁和原生执行
    -> 下一控制 tick 重新测量
```

优先顺序：

1. 先用同一预测函数完成模型一致性复测，报告每个候选的 KKT 回退次数、实际触地时间和非足部触地时间；
2. 对 26 个球侧已合格但恢复失败的回合，保存首次足接触至非足部触地的状态窗口，确认是支撑估计、动作执行还是恢复目标不可行；
3. 将真实救援成功的片段加入恢复头监督，关闭额外 MPC 后检查学生是否保留；
4. 若固定接触 QP 仍无法表达真实事件，再引入少量预定义接触模式和冲量/速度重置近似；
5. 最后再将单步动力学、接触候选和固定迭代求解器改写为 JAX/JAX-XLA 批量版本。不要把 CPU OSQP 包在 JAX 外面当成 GPU MPC。

## 验证口径

每次候选都同时报告：

- 完整成功、合格空中触球、球侧除恢复条件、条件恢复；
- 原 27 个成功的保留/丢失/新增；
- 原 26 个恢复失败救回多少；
- 接触切换、MPC 首步应用、QP solver failure、独立约束拒绝；
- 预测接触时间与实际接触时间误差；
- 预测足端/质心状态与实际 PhysX 状态误差；
- 额外 MPC 开启、关闭，以及恢复头学习后关闭 MPC 的结果。

`27/128` 是当前学生基线；辅助执行成绩不能直接称为 RL 学习收益。当前路线的目标是先得到一类可重复、可解释、预测与实际响应一致的救援动作，再让学生在关闭额外教师后学会它。
