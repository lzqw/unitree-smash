## 模型并没有误判这次头部碰撞

模型候选在25个合格控制区间后被拒绝：下一段预测在3.057375秒发生`Head_lower`几何穿地。原生1ms受力采样在3.057秒记录到合格足端着地后的头部接触。几何事件与大于1N受力不是相同判据，采样分辨率也不同，但二者在约1ms范围内对应。

原生合格足端着地为2.96097秒；原任务评分包含的首次非足部触地为3.699秒，比原学生的4.821秒提前1.122秒。原生恢复窗口未通过，末端根节点高度0.15398米。头部在回合更早的2.211秒也有接触，因此不能把3.057秒称为全回合首次头部触地。

独立比较模型已保存的25步前缀时，严格采用“模型命令t之后的状态对应原生t+1输入”，没有将拒绝之后的状态补齐：

| 已保存前缀最大差异 | 数值 |
|---|---:|
| 机身位置 | 0.456 mm |
| 机身姿态 | 0.00663 rad |
| 关节位置 | 0.0281 rad |
| 关节速度 | 1.445 rad/s |
| 实际与模型反馈目标 | 0.00538 rad |

两条轨迹都使用反馈，因此累计状态差异同时包含反馈命令差异，不能全部解释成固定命令下的模型误差。

另以97个实际状态和实际最终命令做独立10ms预测，97个均完成。两端模型几何净空均超过1mm的52个区间，最大关节速度误差1.438 rad/s；全部区间的最大值10.044 rad/s出现在305步，正是头部碰撞区间。当前模型没有非足部碰撞冲量，此处的大偏差不能作为“无碰撞支撑动力学同样不准”的直接证据。端点净空也不保证区间内部没有接触。

结论限于这一候选：拒绝理由有真实执行对应；继续放宽碰撞约束或将其当作正确监督不合适。它不证明其他候选都不可行，也不排除其他状态中的足端冲击建模误差。
