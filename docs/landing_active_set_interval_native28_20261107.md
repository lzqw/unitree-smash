## 预测模型与执行证据

本候选优化一个控制区间内持有的原生位置命令，使用16子步隐式PD和所有子步约束，求解器为主动集方法。它没有使用本轮新增的关节速度包络或参考轨迹搜索，两项独立CPU候选不能与本成绩混为一谈。

2036个实际应用后可匹配的下一步状态，关节位置预测最大误差的样本中位数为0.00156 rad，95分位0.0294 rad，最大0.2095 rad。它们来自该控制器自己的状态分布，不能直接与另一控制器的误差均值比较来判断模型优劣。

求解墙钟95分位约337 ms，物理仿真在控制边界等待，并未注入同等物理延迟。这说明实现尚不满足实机100 Hz要求，但不能将墙钟耗时直接认定为本次倒地原因。

结论是：改进数值收敛和区间执行建模尚未转化为更好的控制目标。后续应优化整段支撑/收臂/制动安排，保留原生结果筛选，避免仅以模型通过次数选择教师。
