# 恢复MPC的微步接触记录准备

前一轮反事实诊断表明，单次法向力为零不足以支持“整步删除该足接触”的修正。现有记录没有连续物理步的足端受力，因此本轮补齐这个观测入口，**没有修改控制器，也没有新增原生成功率**。

`NativeContactMicrotraceV1`包裹指定环境实例的原`_observe_physics_frame`，每次仍调用原函数一次，随后只读指定lane的状态。它保留原接触力滞回、动作、物理参数与任务判定。每个物理frame只记录一次，保存足端法向力、原接触标志、18关节角和速度、目标缓存、根节点与足端位姿，以及episode编号。目标缓存仅表明当时命令，不能称为实现力矩；法向力也不冒充摩擦力。

默认生成入口记录恢复开始后的20个控制步，当前物理步长下为3201个含端点样本。完成窗口立即保存压缩数组；退出时也会保存已采样部分。缺帧、空窗口和回合重置均显式保留，不能伪装成完整首回合连续轨迹。记录器不额外推进仿真，也不创建专家标签。

已运行5项CPU测试，验证短暂受力脉冲的捕获、原观测与命令不变、重复frame去重、缺帧／空窗口标记、回合编号保留、重复安装及错误足端顺序拒绝。测试使用合成状态，**不证明原生轨迹等价或实际接触模型正确**。
