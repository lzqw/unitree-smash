# 将球拍与全身碰撞形状加入恢复序列优化

2026-11-07。承接 `59a210a` 中5条新增模型解全部球拍穿地的发现，本轮把几何约束真正加入求解，并在原隐式PD/整机动力学下重新优化。没有修改原生任务、资产、速度标准或恢复判定。

## 实现

- 原USD中128个非足部碰撞形状全部参与地面净空，包括机身、腿部、机械臂和球拍。球/网和自碰撞尚未加入本项约束。
- 对球、柱、胶囊、盒和网格计算最低支撑点，利用刚体点雅可比计算构型导数；通过完整动力学序列敏感度传到整段关节命令。
- 网格只保留凸包顶点：83,056个去重顶点降至3,136个，记录约253 KB。线性方向支撑函数不变，没有改变仿真资产。对上一轮6条轨迹共246个姿态，与独立完整几何审计相比，最低点最大差小于1e-10米。
- 优化约束在40个控制边界上建立；非线性检查覆盖每10毫秒内的16个模型子步，以及初始状态。采用地面Z=0、非穿透要求、1e-6米数值容差。该容差没有替换正式任务接触判定。
- 搜索子问题允许一个明确标记的临时几何松弛量，避免初始40厘米穿地直接让局部问题不可解。松弛仅用于找路径；最终接受必须独立通过无松弛几何检查、原动力学约束和原恢复终态。合成回归测试验证了“QP有解且松弛为正”不会被授权执行。

当前仍是离线CPU求解，不是已经部署的实时MPC，也没有把这些输出无差别用于学生监督。

## 联合任务优化

随后从第一阶段结果出发，最多12轮联合优化完整任务代价，再最多8轮可行性修正。6例全部完成，墙钟约302.62秒。

- TRAIN2保持模型可行，它不是新增能力。
- **TRAIN15成为新增的、同时满足动力学、原终态和本轮地面几何条件的模型候选。**
- TRAIN3、18、57、65仍被拒绝，没有因为局部代价下降或求解器返回解而放行。

TRAIN15终端为3足支撑、倾角0.0824 rad、水平速度0.0315 m/s、角速度0.0148 rad/s、支撑裕度0.0697 m；最大原物理约束残差约3.74e-5。另一次独立导出重放再次通过全部模型检查，并用原始完整USD形状重新核对。

它的查询时刻为6.90秒，原回合首次已记录非足部接触为7.76秒；查询并非发生在该记录之后。但它原本球侧不合格，因此只能作为恢复候选，不能作为完整扣球示范。**当前新增原生成功仍为0，学生仍为27/128。**

净空余量仍小：初始Head_lower最低点约1.14e-7米，0.10秒约9.14e-5米；0.4秒末最近部件为球拍握柄，约2.12毫米。这些非穿透结果不能排除PhysX接触偏置造成的接触，也没有证明该模型准确预测了实际承重。

通过候选已独立导出到 `reports/landing_geometry_verified_sequences_20261107/`，明确标记`native_execution=false`、`valid_expert_labels=false`。下一步需要从地面执行相同前缀，在实际查询状态和上一条下发命令匹配后验证预测序列，并继续到原回合结束检查持续恢复；不能只播放0.4秒轨迹就宣称落地成功。该原生验证尚未运行。
