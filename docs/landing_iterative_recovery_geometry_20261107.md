# 迭代恢复优化：找到动力学可行序列，但球拍穿地使新增候选全部被拦截

2026-11-07。本轮实际完成整段迭代搜索、可行性修正、独立导出复核和碰撞几何筛查。**没有新增原生成功，保留学生27/128；不能把本轮5条新增模型可行序列计为恢复收益。**

## 这次改变了什么

此前只对一条名义轨迹求一次增量，再缩小步长；候选虽然降低目标代价，却仍违反非线性重放后的约束。本轮增加两步：

1. **反复重线性化。** 对完整40步、0.4秒命令序列重新传播带机械臂和球拍的动力学，最多6轮优化；内部搜索允许保留暂时不可行的迭代点，但不能执行或作为专家动作。
2. **可行性修正。** 在搜索结果附近最多8轮重新求解，局部目标改为最小命令增量，专门消除约束误差。力矩、速度、限位、摩擦、命令历史、限速和终端恢复条件不变。

4个CPU进程，整项作业900秒外部保护。主动集后端没有可抢占的单次硬截止，这仍是离线优化，不是已实现实时MPC。物理仿真作业与离线代码分开，未修改在跑的原生控制器。

## 独立检查拦截了两个问题

### 圆形摩擦锥与多面摩擦约束的验收交集

首次导出中，TRAIN65通过了原验证器的圆形摩擦锥检查，却仍违反优化器使用的更保守多面摩擦约束，最大违反约0.000899 N，超过原3e-4容差。

没有放宽容差。修正最终接受条件，要求独立终端验证和完整搜索约束检查同时通过，并重新运行全部60个状态。TRAIN65多做一次修正后，最大物理约束违反降到约6.22e-6；最终仍有6条动力学/终端可行序列。真实记录被保存为回归测试，防止再次把圆形锥通过当成全部约束通过。

### 球拍碰撞形状没有进入原整段优化

随后按原USD资产的128个非足部碰撞形状，检查6条轨迹的41个控制边界。使用原始几何、实际加载的刚体运动学和地面Z=0，没有修改资产或判分。

这解释了为什么“动力学约束通过”仍不足以产生可执行恢复：当前目标只对部分腿部连杆原点给净空参考，缺少机械臂和长球拍的真实形状约束。优化器降低机械臂/机身运动代价时，可以提出让球拍穿过地面的路径；真实仿真会产生该模型没有包含的碰撞响应。

为排除简单坐标错误，逐一比较6个查询状态的全部28个刚体与原生记录：位置最大差约6.51e-7 m，旋转矩阵元素最大差约1.43e-6。**这一核对支持运动学坐标一致；不等于PhysX碰撞模型已经复现。**

这里检查的是USD写入的形状，不是PhysX处理后的碰撞几何；只检查10 ms边界，没有完成步间和自碰撞验收。几何筛查已足以拦下约0.4米的球拍穿地候选，但不能给其余轨迹出具安全证明。

部分查询状态的Head_lower几何已非常接近地面。几何接近不等于已确认承重；后续应结合对应原生接触数据，不直接修改原任务判分，也不把这点认定为唯一失稳根因。
