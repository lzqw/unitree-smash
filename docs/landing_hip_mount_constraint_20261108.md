# 新发现：恢复参考遗漏髋部与安装板的避碰约束

2026年11月8日。**此前完整模型检查得到的7/13条有效扰动轨迹，全部在采样状态中出现左前髋碰撞圆柱与机械臂安装板的几何相交。它们只通过了旧约束集，不能再作为完整碰撞可行轨迹。**原生配对接触力确认尚未完成。

## 证据与边界

[一步预测审计](landing_one_step_prediction_audit_20261108.md)将原生误差突增定位到3.64秒附近。新增检查使用资产中真实的髋部圆柱和安装板长方体，而非仅比较包围盒：在圆柱轴向范围内求长方体点到圆柱轴的最小径向距离。

| 检查对象 | 结果 |
|---|---|
| 左前髋与安装板开始几何相交的髋角 | 约 **+0.5690785 rad** |
| 右前髋对应边界 | 约 **−0.5690785 rad** |
| 原生左前髋在3.65秒附近的角度 | 约 **0.569144 rad**，短暂近乎停止 |
| 原模型名义轨迹左前髋最大角度 | 约 **0.65624 rad** |
| 新7/13候选名义轨迹左前髋最大角度 | 约 **0.67045 rad** |

实际髋角停住的位置与几何边界接近，时间也与预测误差突增吻合。这是更具体的候选解释，但**尚不能仅凭几何与时序一致就宣称实际冲量来自该碰撞**，仍需配对法向力记录。

原生记录中，左前髋与安装板有13个采样状态径向间隙小于−1微米，最小约−4.96微米；原模型名义轨迹为21个，最小约−3.97毫米；新候选名义轨迹为22个，最小约−4.50毫米。这里的径向间隙不是完整实体间的欧氏穿透深度。原生微小相交可能与接触求解容差有关，不能据此单独量化碰撞冲量。

髋关节USD硬限位约±1.0472rad。因此这是安装结构带来的额外可用构型限制，不能只按关节硬限位判断动作可执行。后髋在本次扫描区间没有发现与安装板相交，不代表其他自碰撞对均已检查。

## 已加入新的规划检查

新增 `HipMountPathConstraintV1` 在每个预测物理子步检查这两项已审计构型边界，保留0.02rad规划余量。实际资产、关节限位、驱动力、物理引擎和任务评分均未改变。该约束只拒绝穿过安装板的计划，不虚构碰撞冲量或改写实际机器人状态。

新的完整全身轨迹搜索已经启动，联合调整早期与持续支撑的六组18维控制点；所有候选使用160子步预测到原回合结束，保留地面净空、执行器约束及持续稳定要求。首次测试中，原参考已被新增约束拒绝；较大髋部调整可以越过原失败时刻，但仍出现后腿触地或关节约束失败。此时尚不能报告新完整可行解，更不能报告原生成功。

这是约束变化后的重新求解，不要求保留旧7条几何无效的模型轨迹。当前约束仅覆盖已定位的髋部—安装板问题，仍不是完整自碰撞模型。

## 原生作业与调度

原5/13状态跟踪参考的原生执行已完成，旧评分仍为27/128、空中触球74、条件恢复34。未接管TRAIN46首回合由542步变成800步，严格隔离审计拒绝通过；因此数据仍不可作为正向专家标签。

计划撤下7/13候选时，它已自动进入原生运行。为保留完整、不可变输入的对照，该有限时长作业继续运行，不自动提升为可用教师。原等待中的配对观测队列已退役并新建版本，仍串行等待当前作业结束；没有并发启动第二个GPU作业。

随后重放原早期控制器，记录3.55–3.85秒的自身接触对和5.60–5.75秒的跨通道接触对，并与同控制器的128条轨迹检查观测是否改变执行。新队列固定432份输入，单作业2400秒、102400环境步上限。

两项凸几何测试通过，相关新代码语法检查通过。G07正式校验仍未通过。当前最重要的进展是从笼统模型误差定位到可检验的遗漏约束；下一步仍须获得符合约束的完整参考、原生稳定恢复和有效纠正学习收益。
