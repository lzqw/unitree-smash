# 实际连续命令回放：接触转换与恢复计划仍需对齐

2026年11月7日。延续[接受时序审计](landing_acceptance_timing_20261107.md)，对已完成的全18关节控制实验选择8个窗口，使用真实下发的连续关节命令进行CPU预测回放。没有新仿真成绩，没有修改正在运行的学生纠正采集。

## 方法与证据边界

每个窗口从真实状态开始，最多推进40个10 ms控制步。每步使用原生归一化动作按真实关节限位还原的最终目标，和控制日志交叉检查，要求误差不超过5e-6 rad。预测使用现有整机隐式PD模型，每控制步16个子步，模型不会在每一步重新对齐真实状态。

比较两种诊断模式：保持初始支撑集合；逐步注入已记录的未来足端力接触标志。后者是**使用未来信息的离线对照**，不能部署。两者均没有加入真实碰撞冲量、滑移和非足部接触动力学，约束违反量完整保留。

这也不是重放原MPC拟定的整条计划：输入是后来实际执行的连续命令，而非原计划的未来命令；固定接触对照也不是当前MPC全部接触转换逻辑。不得把下面的误差直接当成当前在线预测的误差或新控制器收益。

TRAIN50在3.35秒窗口的姿态误差由约0.559 rad降到0.144 rad。TRAIN98则由0.042 rad增到0.114 rad。因此，不能只凭位置误差改善就认定接触模型全面正确。

TRAIN12的17步真实命令回放已经预测到机身降低：末端高度约0.114 m，实际约0.121 m，位置误差约1 cm。它提示不能将该案例失败全部归因于“动力学模型不知道机身会下降”。仍需核对原计划的未来动作、后来重规划的动作及接触变化；当前日志没有保存每次完整计划的全部命令，不能据此判定唯一原因。

两种回放都出现过预测负法向力或摩擦违反，即使数值方程解得出来，也不构成可执行的支撑轨迹。未来接触标志能解释部分误差，却没有补全单边接触、滑移和碰撞模型。
