## 触地误差已经能定位到足端冲量

此前事件审计显示，大多数无非足部碰地、无触网的10毫秒区间预测较接近实际，但少数首次触地／支撑区间出现很大关节速度误差。本轮针对其中四个异常区间，另取五个成功案例的首个支撑区间作为对照。

模型从该运行真实全身状态出发，重放同一实际最终关节命令，累计160个物理子步的四足冲量。原生数据使用同一10毫秒内累计的法向与摩擦冲量；不是拿最后一个采样力代替整段作用。

| 案例:步 | 总足端冲量向量误差（N·s） | 最大关节速度误差（rad/s） |
|---|---:|---:|
| 33:298 | 0.8144 | 20.943 |
| 96:306 | 0.6643 | 13.761 |
| 87:304 | 0.2933 | 4.051 |
| 71:301 | 0.3347 | 4.435 |
| 五个成功案例对照 | 0.0025–0.0082 | 0.0038–0.0672 |

四个异常区间的冲量误差集中于实际承载足。比如33:298右前足冲量误差约0.8114 N·s，左前足只有0.0074 N·s。这说明异常并非只有一个关节速度字段不一致，地面加载过程也存在差异。

用原生前后状态及资产惯量重建线动量，再减去重力和实测足端冲量，33、87的剩余量分别约0.00059、0.00046 N·s；71约0.00595 N·s。96仍有约0.0817 N·s未解释剩余，不能对它声称已完整排除观测、惯量或其他约束响应影响。

九个区间均返回预测，新增冲量记录没有改变原预测的最大关节速度误差，变化为0。实际区间无非足部地面和球网受力，模型也未报告非足部穿地。

这是有针对性的异常样本对照，不是总体误差分布，也不能证明冲量误差是全部失败的唯一根因。它尚未区分接触几何／时间、摩擦响应、关节约束和其他内部碰撞各自的贡献，不能据此随意修改摩擦或加大电机能力。
