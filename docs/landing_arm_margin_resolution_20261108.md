# 恢复前缀的机械臂速度余量与积分分辨率

**本轮修复了模型候选中的两个扰动失败，但还没有新增原生恢复成功。** 原学生系统仍27/128；GPU0滚动优化对照和其后的终端控制器原生队列保持原输入。逐项结果和哈希见[JSON](landing_arm_margin_resolution_20261108.json)。

## 改动与完整扰动复查

上一轮定位到，髋部负向扰动会通过全身耦合使机械臂 `joint2` 瞬时超过5 rad/s。本轮保留腿部反馈、终端支撑参考和全部硬件参数，只在恢复偏移步15–45对 `joint2` 的位置请求增加一段半正弦修正：

`delta = amplitude * sin(pi * (offset - 15) / 30)`，窗口外为零。

在0、−0.001、−0.003、−0.006、−0.01 rad五种幅度下，分别实际运行名义轨迹与两个已知失败扰动，共15项。−0.001已能让两个失败通过现有数值容差，但最坏峰值仍为5.000055 rad/s，余量不足。因此选用−0.006 rad候选复查原来的全部8个扰动条件，而非直接提升原限制。

| 条件 | 原持续反馈 | 加入机械臂平滑修正 |
|---|---:|---:|
| 无扰动复现 | 通过 | 通过 |
| 四种前缀髋部扰动 | 1/4 | **3/4** |
| 四种终端小腿扰动 | 4/4 | **4/4** |
| 扰动条件合计 | 5/8 | **7/8** |

通过条件仍要求剩余340步全部通过原路径约束，并至少有0.8秒模型运动学稳定窗口。−0.006候选的名义 `joint2` 峰值为4.962371 rad/s，两个负向扰动峰值为4.968536和4.963466 rad/s；对应窗口0.98和1.01秒。所有通过的终端扰动仍有0.96–1.10秒窗口。

剩余失败是+0.02 rad髋部扰动在偏移步1造成的 `Head_lower` 微米级几何越界。机械臂修正从步15才开始，所以不会修复这一更早的事件；没有修改净空容差将其算作通过。

## 更重要的检查：旧候选依赖积分分辨率

固定控制器和初态，不重新优化轨迹，仅改变每10 ms控制周期内的预测子步数量。原生PhysX每控制周期160物理步；这里使用相同子步数量仍不等于复现PhysX接触求解器。

旧候选在16子步的轻微超量低于原3e−4数值容差，增加分辨率后却明显越界。因此，原来的“模型通过”只对已声明离散设置成立，不能当作已经有充分执行余量。修正候选通过四种分辨率，是更强的模型证据，但仍未证明原生精度、扰动区域或真实恢复。

原任务、电机PD、力矩能力、速度限制、机械臂目标限速和完整成功判定均未改变。模型仍缺少非足部碰撞响应等PhysX细节，不能由这项检查宣称预测模型已经等价。

## 对MPC的具体影响

1. **前缀优化必须约束全身内部峰值。** 腿部反馈会改变机械臂速度；控制周期末小于上限不代表周期内没有越界。
2. **接近硬边界的解需要额外余量与细积分复核。** 不应只看优化器残差或放宽数值容差。当前细积分仍有约0.023 rad/s名义速度余量，是否足以覆盖原生偏差尚未证明。
3. **终端反馈继续覆盖整个剩余回合。** 本轮修正保持原80步前缀加260步持续反馈；不是短时扶正后直接退出，也没有从理想末态开始。
4. **最终仍以原生完整回合判定。** 模型修复7/8不是任务成功率。现有原生对照不改输入；改进候选单独保存后，需做同条件原生验证，再决定是否形成专家数据。
