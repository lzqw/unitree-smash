## 下一版解除的是哪种限制

旧搜索保留恢复段最初50、50、30个控制步。这是用于保留已有运动的搜索选择，不是硬件或成功标准；当前结果没有证明这些早期动作适合后续恢复。

新版本从同一个实际球分离初态出发，允许全18关节从第一条恢复命令起共同优化，仍计算到原回合8秒结束。原准备、起跳、击球前缀不变，关节范围、速度、力矩、碰撞与最终稳定要求均不变。没有把模型中间状态传送进Isaac。

已有部分轨迹仅用于初值：先准确重建其“已检查前缀＋样条后段”的命令，最大重建误差8.89e−16 rad，再采样为新的完整恢复控制点。**重新采样会改变插值曲线，不能把新旧实验解释成只改变冻结权限的严格单因素对照。**第一条目标允许优化，但仍通过原位置PD与真实执行器限制。

新搜索已实际启动：`reports/pure_control_released_prefix_search_20261109`，4个CPU工作进程、2400秒规划期限、外层2700秒保护，全部候选使用160子步。输入核查直接与已完成原生记录的q、v、上一目标和足端受力匹配；原硬件与命令配置由来源哈希固定。当前没有新结果。

后续协调器只在找到完整模型路径时执行独立闭环反馈及回合末检查；无完整路径则结束，不自动重试、不占GPU、不生成专家标签。
