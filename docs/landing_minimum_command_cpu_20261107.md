# 最小命令改动不能压过完整预测可行性

2026年11月7日。独立CPU候选在全身18维区间命令QP中增加
`0.5*w*||q_target-q_student||²`，使用原QP数值归一化后的权重w=1。
原力矩、速度、位置、摩擦、机械臂目标变化率和所有隐式子步约束不变。
零权重与原QP逐位一致的检查、物理命令到优化坐标的二次代价检查、
受约束实例的改动下降检查和非法权重检查均通过，共4项。

对实际全128学生＋教师运行的全部活动控制记忆逐步回放，在每例首次活动和
每100个控制步求解，共393个状态。比较的是原全18维区间控制器与新增代价，
不是把此前35/128命令历史控制器的成绩直接套过来。

| CPU预测指标 | 无新增代价 | 命令改动代价w=1 |
|---|---:|---:|
| 首步可行 | 262 | 262 |
| 完整40步预测通过 | 90 | 45 |
| 共同可行首步的平均改动范数 rad | 0.9263 | 0.1927 |
| 改动范数95分位 rad | 1.6994 | 0.5246 |
| 累计求解时间 s | 58.74 | 57.28 |

262个共同可行首步没有出现新增代价后命令距离增大的情况。
但新版本45个完整预测全部属于原90个可行预测，另外45个被破坏，没有新增。
**因此不直接上线该无条件代价版本。**少改学生命令不是绝对目标；真正恢复
可能需要必要的大幅修正。下一候选应优先保留完整预测可行性，在新计划不通过时
从同一真实状态和同一控制记忆重新求原计划，不能用更小命令变化补偿未来不可行。

此处预测使用当前学生请求作为保持参考，没有滚动运行未来学生策略；
CPU预测通过不等于原生恢复成功。记录状态也包括已失稳状态，不将393个状态
解释为393个独立任务。实时原27学生全案例教师对照保持原配置运行。
