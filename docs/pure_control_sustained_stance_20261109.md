# 纯控制落地：根据实际状态建立持续支撑目标

2026-11-09，北京时间。延续冻结击球前缀、球分离后单一控制器接管18关节的路线；没有新RL、BC或蒸馏。原关节、力矩、实际速度、碰撞、5m/s任务及稳定判定保持。

## 本轮解决的问题

上一版在优化参考结束后立即保存当前构型，再持续用全身QP跟踪。它救回了TRAIN61的晚期模型失稳，但扩展检查揭示两个反例：TRAIN64在反弹尚未结束时转换，约1.02秒球拍触网；TRAIN118保存了超过稳定范围的倾斜姿态，虽然没碰地，末尾仍不合格。12例检查中只有10例满足完整模型路径与最终稳定，不能将该版本直接推广。

v14把“参考结束”和“适合建立持续支撑目标”分开。参考结束后仍持续求解原全身控制；只有当前观测足端支撑、姿态、线速度、角速度和关节速度符合原瞬时稳定范围，且模型几何没有非足部穿地，才保存实际达到的质心、姿态和关节构型作为软目标。

这不是把关节命令保持不动。QP、状态反馈、原位置PD和实时接触继续更新；没有锁死接触，没有虚构地面力，没有加入学生残差。瞬时条件只决定软参考，不证明安全，也不代替完整回合末的持续稳定。
