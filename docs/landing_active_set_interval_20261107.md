## 先分清求解失败的含义

对新区间控制器在旧35轨迹上拒绝的30个首步，用独立HiGHS线性可行性求解器检查完全相同的约束：16个有可行解，14个在当前模型内不可行。模型包括固定接触、未饱和隐式PD分支和内接摩擦多面体，因此后者不能被称作硬件物理不可能。

保持原物理约束，将OSQP从10000次迭代提高到50000次，并由可行点初始化，有10个通过独立检查。单纯增加迭代仍没有解出全部16个。

当前环境已安装 `quadprog 0.1.13`。用其Goldfarb–Idnani active-set算法交叉求解同一个严格凸QP，逐项核对Hessian、线性目标、约束矩阵和上下界完全相同：**16个可行问题全部通过，14个冲突问题仍拒绝**。没有增加Hessian正则、放宽摩擦、增加力矩权限或改变残差验收门槛。

这次配对中，OSQP再次运行通过1个，而此前相同问题检查为0个；数值自适应过程可能影响边界收敛表现，不能把两次结果当作绝对确定的求解率。active-set的16个结果均通过原独立16子步积分，最大物理检查残差约4.63×10⁻¹¹。

30个问题的求解器累计时间约为OSQP 4.478秒、active-set 0.00827秒；这是此批小型稠密问题的CPU测量，不是通用速度承诺。包含模型构造及滚动预测的479状态完整审计耗时142.31秒→78.59秒，更接近整个控制计算的变化。
