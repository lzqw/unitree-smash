# 有效击球后的完整恢复候选与原生预测核对

2026-11-08。本轮保持纯控制路线：冻结已有击球前缀，不训练RL、BC或蒸馏。球分离后使用全18关节控制，原关节、执行器、碰撞和任务条件保持。以下模型结果不计为Isaac落地成功。

## 从短尾段调整转为完整动作搜索

上一版固定最初300毫秒，只优化后续1.3秒。三个原本球侧合格、恢复失败且已有短模型参考的案例中，只有TRAIN12通过整个模型时域，末尾仍不稳定；TRAIN50触网、TRAIN58碰头。

这次允许调整从实际球分离状态开始的全部1.6秒。优化八个控制点、18关节总目标，采样包含腿部伸缩、左右落脚和收臂方向，仍限制在原硬件范围内。没有扩大力矩、删除碰撞、瞬移原生机器人或把目标变化率当作实际关节速度。

三个案例均通过160物理子步/控制步的1.6秒模型复核。随后从同一记录初态重新执行这些命令，控制器记忆逐步更新，再交给连续全身反馈，直到原8秒回合结束。没有直接载入候选终态。

前三个1.6秒重放的状态与搜索细模型逐步结果误差为零。这是重放一致性证据，不是独立物理引擎验证。模型包含足端摩擦、原位置PD、关节限制及部分髋部安装处自碰撞；其余自碰撞和非足部碰撞响应未完整建模，路径拒绝也不能代替PhysX接触验证。

这三个来源在原基线中满足球侧条件，因此比此前仅在未合格回球状态上找到的模型恢复更直接关联完整任务。但恢复时仍可能二次碰球、触网或改变后续规则结果，只有从地面完整执行才能确认新增完整成功。

有限搜索成功说明找到了模型候选；前一版搜索失败不构成物理不可恢复证明。三个案例的结果也不构成全部26个恢复失败的覆盖率。

## 旧版失败不宜继续笼统归因于执行器模型

对已完成的v7原生记录，使用实际状态和实际下发目标进行一步重放；预测时没有累积此前的轨迹误差。分别检查分离、首次观察到足端支撑、非足部碰地前一控制区间及碰地区间。

110个分离时刻均得到模型响应。10毫秒后机身位置误差中位数约0.018毫米，世界线速度误差约0.000048米/秒。这说明当前模型在这些空中一步响应上较准确，不能再把所有控制失败都解释为位置PD完全不可预测。

在首次观察到足端支撑的记录中，很多案例已发生非足部触地。剔除之前或当前区间已有该接触的样本后，剩29条，其中26条得到模型响应，3条被网碰撞检查拒绝；有效响应的线速度误差中位数约0.00273米/秒，最大关节位置误差的中位数约0.00316弧度。这个条件样本不能代表所有触地冲击。

非足部碰地前一控制区间有86条记录，77条得到模型响应。其线速度误差中位数约0.00043米/秒，但存在明显尾部误差和模型拒绝，不能只报中位数。

更关键的是，首次非足部碰地所在区间的77条记录中，**76条实际使用了未认证姿态回退，仅1条使用QP命令**。在前一区间，不少命令仍被短区间QP接受。这支持一个具体诊断：局部可行性维持得太晚，随后失去可行支撑时回退动作不能救回身体。它不是对唯一因果的证明，但说明需要改善更早的落脚与缓冲计划，而不只降低求解失败数。

进入非足部碰地区间后误差骤增也符合模型缺少相应碰撞响应的限制，不能把这部分误差单独归因于电机或PD。详细分组分位数、拒绝与实际命令来源均保留在紧凑证据中。

## 动作余量与覆盖范围

按优化命令重放的10毫秒采样，三例首次出现模型足端支撑约在球分离后0.24、0.25、0.24秒，采样最低头部净空分别约7.01、1.54、4.70厘米。TRAIN50仅约1.5厘米，仍可能受真实触地误差影响。这里报告的是控制边界几何样本，不能当成所有物理子步或原生执行的最小净空。

三例都没有要求四足同时着地：TRAIN12约0.29秒出现四足模型接触，TRAIN58约0.30秒，TRAIN50则约0.84秒。它们通过不同的模型预测接触序列进入稳定，而非在首次接触时硬拉到统一站姿。是否在PhysX中也能实现相应加载，仍需下一轮实际证据。

完整基线中共有26个“球侧合格、恢复失败”状态，三例模型候选之外仍有23例。已从真实分离状态库自动选出这23例，使用同一套1.6秒全18关节搜索、相同损失与硬件约束完成1817个粗模型候选。三个模型方案只提供通用初值，不作为专家标签，也不在运行时按TRAIN编号指定动作。仅直接套用初值时，23例中只有1例通过粗模型1.6秒时域，因此不能将三条动作视为覆盖全部失败的教师。

统一搜索耗时892.7秒，9/23例通过1.6秒细模型路径检查：TRAIN9、18、30、42、54、61、77、85、90。其余14例中，6例头部碰地、3例其他非足部碰地、5例球拍与网发生冲突。没有案例因本轮计算预算提前截断；搜索失败仍不等于物理不可能。

这9例在1.6秒结束时均未形成0.8秒连续稳定，必须继续执行至原回合末。全9例已完成：TRAIN9、18、42、54、85、90在模型中稳定到回合末；TRAIN30、61、77分别在分离后约1.90、1.97、2.23秒出现髋部或球拍碰地。合并此前TRAIN12、50、58，原26个目标状态中有9个模型全回合恢复候选；这不是9个原生成功。

### 为什么另外三例在后段失败

独立记录器重放上述三例及TRAIN9、18、42三个成功对照，记录最终命令、实际模型状态与QP拒绝。全部六例的重放轨迹与原细模型验证前缀完全一致，记录本身未改变控制结果。

在1.6秒的参考交接点，三个失败案例均只有前三只脚承重，右后足尚未建立模型接触；三个成功对照均有四足接触。失败案例此时横滚约−21.2°、−36.2°、−22.5°，仍未达到稳定站立条件。TRAIN30、77已被宽松的阶段条件标记为SUSTAIN，但这个阶段标记不等于正式稳定通过。

交接时，失败案例最大单步目标变化分别约0.668、0.279、0.340弧度；成功对照也出现约0.330、0.494、0.403弧度的变化。因此，命令跳变是真实存在的接口现象，但大小本身不能区分成败，不能认定增加限速就能解决。

TRAIN30、61的QP在碰地前仍持续返回可行命令，到碰地区间才报告primal infeasible；TRAIN77则在碰地区间因独立动力学／几何复核拒绝。三者随后均使用未认证姿态回退。更具体的待修问题是：轨迹时长结束并不代表承重布局已经完成，当前常规站姿目标与单区间QP不足以保证三足状态继续建立可持续支撑。下一版需要把支撑建立和稳定终态纳入连续计划，而不是只延长一帧命令或重新扫描反馈增益。这是模型中的诊断，仍需原生证据验证。

这些新参考只进入独立CPU模型库，未替换正在运行或已经固定输入的原生作业。当前原生v9仍为旧31条短参考对照，尚无最终成绩。模型恢复与原生结果不能混写。
