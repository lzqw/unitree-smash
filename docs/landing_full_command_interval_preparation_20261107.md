## 对最新审查意见的处理

原来的接触观测是接触力范数1 N/0.5 N滞回，不能叫独立几何接触；当前承重阈值与该标志不同也不直接构成失稳归因。后续不把37条判据不同或求解次数变化当作恢复收益。

当前推进重点已经是持续反馈、命令历史及执行器一致性。区间候选直接优化实际位置目标，以带负载整机约束构造隐式PD子步响应；终态来自同一预测路径。它仍是固定接触、局部动力学线性化及近似触地事件模型，不能称为精确PhysX回放。单步响应误差改善也不能证明数百毫秒预测可靠。

进一步审计表明，部分首步可行状态会在后续撞上关节位置边界、根高度约束或终端支撑条件。只在已不可行时临时允许机械臂动作，无法解决多项后续冲突。因此下一版尝试机械臂和腿持续共同优化，并提前约束接近限位时的关节速度，仍保留原质量、力矩、物理速度、目标变化率和任务判定。
