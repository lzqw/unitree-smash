## 新发现：0.8秒候选还不能连续接续

上一轮找到的0.8秒候选通过了模型路径约束与末端条件，但按原恢复运动学条件逐帧计算，最长连续合格窗口只有 **0.03秒**，不是要求的0.8秒。

本轮从同一原生实测初态开始，在模型中执行前10步，再用相同规划器重规划。第一轮通过；执行100毫秒后，移位初值延长至新的80步时域未通过。四轮CEM把最大归一化违反量从0.877降到0.244，仍违反末端倾角、角速度和关节速度条件。检查停在10/340步，没有声称到达原回合末端。

这里除初态以外的状态都是模型预测，**不是新采集的原生观测**。它证明的是当前规划器尚未展示连续可行能力，不能据此证明真实状态不可恢复。

## 同一个失败状态可以找到更好的后续序列

保留该失败状态的q、v、接触状态和已执行命令历史，使用局部有限差分与约束QP修复后续控制点。三轮修复的最大归一化违反量为：

```text
0.87668 → 0.30458 → 0.02737 → 0
```

最终候选经过另一工作进程独立重放，通过原非线性检查；没有放宽任务、硬件、几何或数值容差。修复耗时292.65秒。末端roll约−0.25993 rad、角速度0.92136 rad/s、最大关节速度0.99983 rad/s，仍接近部分边界。

这表明在这个保存状态上，有限CEM失败不等于不存在可行后续动作。但新增序列仍只证明一个预测时域可行，没有证明后续所有滚动时域都可行，也没有证明实际稳定恢复。下一步需把这种修复接入持续规划，继续验证更长的稳定窗口，不能只积累单次末端通过的候选。
