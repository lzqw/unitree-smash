# 实际区间动量与MPC平均支撑力核对

本轮检查已完成原生V1的TRAIN3第460—477步，即4.60—4.78秒；没有新增GPU重跑或成功成绩。使用各步实测全身q/v、已准入的整机质量与运动学，计算世界坐标下的整机线动量，比较同一实际命令的160子步模型预测。

计算关系为：

\[
\bar f_{ext}=\frac{m\dot c_{t+\Delta}-m\dot c_t}{\Delta}-mg,
\qquad \Delta=0.01\mathrm{s}.
\]

该量是区间平均外力的推算值，**不是实测逐足作用力**。归因于地面支撑需要区间内没有显著其他外部冲量。本段未记录球拍触球事件，首次非足部触地也晚于本段；传感器阈值以下的其他作用、端点状态精度及模型运动学误差仍是限制。整机质量为20.7099913 kg，保留机械臂和球拍。

| 比较量 | 18步RMSE | 最大绝对误差 |
|---|---:|---:|
| 模型平均总地面力−动量推算外力，X | 0.650 N | 2.614 N |
| 同上，Y | 1.449 N | 5.540 N |
| 同上，Z | 0.476 N | 1.137 N |
| 原生端点采样法向力−动量推算区间平均力，Z | 19.252 N | 见证据JSON |

例如第460步，动量推算平均外力约`[-117.62,20.08,209.84] N`，模型区间平均地面力约`[-120.23,14.54,208.70] N`，而原生端点法向力总和为197.81 N。端点量与区间平均量不能直接视为同一目标值。

独立核对了线动量与Pinocchio质心动量的线性部分一致，并用固定构型、纯基座平移检查世界坐标变换，两项最大差均为0。本轮全部输入哈希复核一致，正式G07验证仍FAILED。

## 对后续优化的影响

这批数据支持：模型的**整机区间平均支撑合力**已经较接近实际状态变化。它不支持“因端点足力不同，整个模型总支撑力必然严重错误”的解释，也不能由此宣布预测模型完整正确。

单足受力分配可能不同，即使合力接近；左前髋速度偏差仍存在。接触时序、关节执行偏差、长时域预测和实际持续稳定窗口需要单独检查。上一轮强制移除左后足使预测变差，因此暂不把基于端点零力删除接触作为控制修改。

当前原生V2仍在求解，最新已保存进度为第572步、20次重规划、112步教师动作、0步回退。稀疏事件快照显示5.655—5.757秒后腿关节速度再次高于1 rad/s；该瞬间不满足恢复速度条件，但不能仅凭稀疏样本判定整个回合失败或连续稳定窗口。未倒地与满足持续恢复仍需分开报告。
