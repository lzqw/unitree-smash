# 纯控制恢复：在实际状态允许时转入持续支撑

2026-11-09。本次增加的是独立CPU模型对照，原生GPU作业与排队输入未改动。没有训练RL、BC或蒸馏。严格落地段原生最佳仍为5/128，五例在接管前都有头部接触，不能称为整回合无碰地成功。

## 新证据与假设

精细模型直接优化中的27:274候选，已从实际释放状态连续执行371个10毫秒控制步，随后右前髋触地。其间曾出现最长约60毫秒的原判据稳定状态，但没有维持到原8秒回合末。这个候选仍是失败轨迹。

固定快照显示，约第250个模型步时，机身横滚、俯仰约为−2.3°、−5.9°，水平速度约0.151 m/s、竖直速度0.020 m/s、角速度0.336 rad/s、最大关节速度0.919 rad/s，四足有观测接触。到第350步，横滚增至约15.7°，水平速度约0.49 m/s，左后足失去接触；随后进一步倾倒。

现有V15只有在已选择的参考轨迹结束后，才允许按当前状态建立稳定支撑软目标。这意味着一条尚未完整优化好的轨迹，即使中途短暂到达适合尝试稳定支撑的状态，也可能继续将机器人带离该状态。

本次假设是：不必强制执行到参考末尾，可以在当前状态满足原瞬时稳定及几何条件时，转入持续全身支撑反馈。它不能保证成功；短暂满足条件也不是稳定域证明。

## 实现与对照

新增V23继承V15的全身位置执行接口、支撑QP和足端软目标。唯一的结构性改变是：已选择参考的执行过程中，当前真实/模型状态一旦满足原瞬时稳定与净空条件，即记录当前质心、姿态、关节构型及足端位置为软目标，停止追踪余下参考曲线，持续求解全18关节命令。

它不保存虚构接触力，不把落脚点锁存等同于永久接触。支撑约束仍使用当前观测；没有足端支撑时，原来的腾空物理处理仍保留。成功仍要求无非足部触地并满足原连续稳定窗口到回合末。

对六个实际释放状态做成对完整模型执行：

- 原V15：参考结束后按状态尝试持续支撑。
- 新V23：参考期间也允许按当前状态进入持续支撑。

两者从相同原生初态、使用相同候选快照与原硬件接口，均执行到8秒或明确物理失败。每个控制步采用160个模型子步。六个候选在读取时原子复制为独立快照；正在搜索的源文件后续变化不影响本轮对照。这些快照包含失败候选，只是诊断参考，不是专家示范，也不代表已获整段认证。

本轮4个CPU工作进程、1800秒计算预算、2100秒外层保护。没有启动新GPU作业。模型反馈对照仍在运行，不能提前宣称原生成功率提高。

## 已完成检查

六个释放初态上，两种控制器的首条命令最大差为0。对27号候选中第一个满足条件的模型状态，确认新控制器停止旧参考、使用当前支撑反馈；去除实际接触标志后，同一状态不再满足切换条件。该检查还确认没有改写接触标志、输出处于原关节范围内、没有将切换标为成功。

这些检查只验证动作入口与因果门控，不是完整控制效果证据。正式G07结构校验仍失败，原因是历史缺失检查点、资产外部路径与缺失的G07证据，未改验收契约。

最终需要比较：实际切换是否发生、是否避免晚期非足部触地、是否持续稳定到8秒，以及模型收益能否通过原生完整回合复现。若未发生切换，不能将结果解释为该支撑方法已经被检验；若只是推迟倒地，也不计为成功。
