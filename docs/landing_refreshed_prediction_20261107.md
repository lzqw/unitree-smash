# 子步更新全身动力学：尚未解决角速度预测偏差

2026年11月7日。在[相邻原生状态核对](landing_native_prediction_groups_20261107.md)之后，补充一个明确的模型近似对照：保持实际下发命令、原始物理参数、16个积分子步和初始接触集合一致，仅将冻结的M、h、J和Jdot改成每个子步按预测状态更新。

数据来自已完成35/128和28/128运行中实际应用教师首步的243、104个样本。每条都对照10毫秒后的真实状态；冻结模型的四项误差逐值复现前一审计，差值小于1e-12。两种预测在347个样本上均数值完成。

| 35/128 | 冻结矩阵 | 0.018329 m/s | 0.089482 rad/s | 0.003882 rad |

区间控制数据的线速度预测有所改善，角速度误差基本不变；另一组角速度误差略增。**现有证据不足以将逐子步更新作为当前控制器的替换方案，也不足以认为冻结动力学矩阵是主要失稳原因。**

两种模型仍固定初始接触集合，持续施加相同的接触速度约束，未完整模拟触地、脱离、滑动及非足部碰撞。因此，这个对照只检验局部动力学更新，不能排除接触和执行响应的其他误差。不同运行到达的状态不同，不将跨运行误差差异视为因果结论。

本轮为CPU诊断，未改变正在运行的全18关节控制试验或后续采集配置，没有新增GPU成绩，也没有把预测动作加入正向学习标签。全身联合控制仍等待800步完整结果；当前保留的学生基线27/128和条件辅助35/128不变。
