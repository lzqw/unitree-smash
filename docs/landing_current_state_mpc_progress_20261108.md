## 为什么不能只找到一条模型轨迹就推广

最近对同一新候选的13个状态交叉检查中，原计划通过11例，新计划通过10例；新计划救回2例、同时丢失3例。两个修复输出实际上是同一组动作参数，不能当成两个独立候选成功。

因此保留原计划，不做全局替换。模型内“某状态可恢复”必须与控制器适用范围、实际执行和整回合结果一起核对。有限搜索失败不等于硬件物理不可恢复。

另一个学习接口限制已经出现：近期教师在28个控制步上，与学生同状态命令的腿部目标差超过当前残差接口可覆盖的必要范围。不能直接把这些绝对目标当成原残差网络的正确标签；这也不证明学生不能通过其他轨迹完成恢复。
