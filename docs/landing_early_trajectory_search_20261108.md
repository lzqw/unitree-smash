## 实际完成的工作

以TRAIN3从地面执行到tick300的真实记录状态为初态，保留20.709991 kg完整腿臂球拍模型、原位置PD、力矩／速度／位置限制、摩擦和非足部净空要求。

新增搜索联合调整四腿在0.08、0.20、0.50秒的三个关节目标节点，用PCHIP形成连续命令，并持续使用接触相关姿态反馈。第一条命令严格等于此前实际下发命令；机械臂平滑制动到查询时的实测构型，保留原目标限速。**这一版搜索36维腿部轨迹，机械臂参考尚未作为独立搜索变量，不能称为完整全身轨迹优化。**

每个候选的目标都是从原3秒查询持续到8秒回合末，共500步，并通过末端支撑余量和最后0.8秒稳定窗口；路径首次违规立即拒绝。没有为了通过搜索缩短最终恢复要求。

运行64个候选×8代，共512次粗分辨率检查，约178.8秒CPU墙钟时间。挑选两个最有希望的候选，用160子步独立复核。粗筛的失败排序优先考虑约束内持续时间和首次碰撞时刻，不能让“更少动作、但更早倒下”仅凭低动作代价胜出；该排序只是搜索启发，不是成功判定。

## 结果：推迟了模型碰地，没有恢复成功

512个候选均未达到完整可行。最佳粗筛候选可完成15个控制步；两个精细复核候选同样在第15区间出现头部地面违规，首次发生约为查询后0.159秒和0.158秒。零稳定窗口，没有可用的正向专家标签。

相比上一轮简单站姿参考约0.125秒的模型头部触地，部分候选推迟了碰地；这不能当作稳定恢复改善，更不能算原生成功。

## 为什么它仍会碰头：独立重放的模型受力证据

新增只读观测器记录摩擦求解每个物理子步的足地冲量和实际模型电机力矩。观测前后返回同一求解结果，重放的所有已保存q/v／目标命令最大差异为零。以下数值是**模型冲量换算的法向力，不是Isaac测量力**。

| 相对查询的控制区间 | 模型承重情况 | 关键现象 |
|---|---|---|
| 0—4 | 四足均无支撑 | 身体继续下降 |
| 5 | 左前足开始建立接触 | 本区间仅约9%子步受力超过1 N |
| 7 | 两前足建立承重，后足仍离地 | 平均前足法向力约186、319 N，包含触地瞬态 |
| 10—14 | 两前足持续承重 | 左前大腿逐步进入23.5 N·m力矩饱和；后足仍未接地 |
| 14，最后完整无违规区间 | 前足平均约196、180 N | 后足净空仍约0.217、0.405 m；根部仍以约1.518 m/s下降 |
| 15 | 两前足仍受力 | 头部先触及模型地面，路径被拒绝 |

整机重量约203.2 N，因此不能把这条轨迹简单解释成“接触判断为零”或“支撑力始终小于重量”。它确实建立了前足支撑和减速，但在当前姿态、下落速度、落脚位置与力矩约束下，没有在头部触地前把运动接住。

上述是这一个失败候选的模型机制，不能直接推广到全部26个原生恢复失败，也不能证明其他控制序列不可行。足端力超过重量不意味着根部会立即停止下降；根部速度也不等同于整机质心速度。

1. 保留当前完整反馈尾段MPC的原生对照，不中途改配置或放松约束。
2. 新的早期候选需要联合机械臂和腿部轨迹、接触建立时序及姿态过渡；本轮机械臂固定制动的搜索空间还不能回答全身能否救回。
