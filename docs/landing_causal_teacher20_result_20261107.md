## 严格历史轨迹审计失败：保留并拆开解释

原严格审计发现18个案例在自身教师介入前已偏离历史基线，自动停止后续队列。这个失败没有被删除，也没有放宽原审计容差。

逐帧核对显示：

- 直到全局首次改变教师命令的第295步，全部案例的观测逐位相同，此前命令也逐位相同。
- 18个偏离案例主要在第315步开始变化；此前一拍观测和命令仍与历史记录相同。存在后续差异放大，不能全部称为可忽略浮点误差。
- 该18例均不在原53个球侧合格集合。原53个、包含原27个成功的案例，在各自介入前的轨迹均通过原有误差阈值检查。
- 因果门控可由当时公开观测逐步重建；未介入时最终命令与当前学生请求完全相同；40036条命令记录均与实际轨迹匹配，误差上界3.22e-7 rad，手臂目标限速无违反。

新审计因此只确认“因果调度与实际命令一致、全局改动前轨迹一致、53个球侧合格前缀一致”，明确标注“全部lane历史前缀一致”为false。没有证明不同并行案例的物理执行完全互不影响，也未唯一确定上述差异原因。

PhysX官方说明确定性依赖相同场景、步骤及调用条件；场景约束处理改变可能影响结果。因此，其他环境命令改变后的逐lane历史复现不能仅凭名称当作必然不变量。这是排查依据，不是本项目差异已被归因到PhysX的证明：[PhysX确定性说明](https://nvidia-omniverse.github.io/PhysX/physx/5.4.1/docs/RigidBodyDynamics.html)。
