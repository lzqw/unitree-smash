# 落地MPC：摩擦接触预测、0.8秒候选与原生持续反馈

2026-11-07，北京时间。精确快照时间、来源哈希与进程状态见[紧凑证据](landing_frictional_feedback_candidate_20261107.json)。

## 当前结论

学生系统基线仍是 **27/128**，74次合格空中触球、34次条件恢复、53次除恢复外全部合格。本轮没有新的教师关闭学习成绩，也没有宣布原生恢复成功率提高。

有一项明确的新进展：在包含足端球面接触、摩擦冲量和隐式PD响应的新预测模型中，找到TRAIN3的一段 **0.8秒可行候选**；用原生仿真实测查询状态重新求解、独立重放，也通过同一套约束。新控制器已经进入GPU0后续队列，等待旧模型反馈实验及审计结束。

**0.8秒轨迹末端通过恢复约束，不等于满足原任务连续0.8秒稳定窗口，更不等于完成8秒原生回合。**

## 为什么调整方向

用户指出接触观测来自力范数滞回，不能称为纯几何接触，这一判断成立。当前工作已越过单纯阈值扫描：明确区分传感器接触标志、当前受力、模型中的足端球面几何与未来可承载状态。接触标志不能凭锁存产生悬空支撑力。

旧模型的340步名义轨迹已实际完整下发。固定面板仍27/128，TRAIN3恢复失败，记录的首次非足部接触从基线5.145秒提前到4.908秒。命令映射最大误差只有1.82e-7 rad，因此这次不能归因于“规划指令根本没有送到执行器”。旧名义轨迹最后可观测状态的根位置误差约0.176 m、姿态误差约0.394 rad，说明精确下发并不足以弥补长时预测偏差。

对该次原生执行的同一实测状态、同一真实命令进行一步预测比较：在首次记录到非足部接触前的30个样本，新摩擦模型的腿关节位置误差P95由0.01029降至0.002763 rad，23个改善、7个变差。这支持继续检验新预测模型，但不能证明所有PhysX响应已被复现。原传感器未覆盖的部件接触仍是诊断边界。

## 本轮实际实现

1. **约束敏感度修复。** 原80步CEM候选仍违反终端倾角和路径速度条件。新增局部有限差分与QP方向求解，对后半段三个全关节控制点进行修正；每个方向都重新运行完整非线性预测。两次迭代把最大归一化违反量从0.09538降为0。QP松弛只帮助提出方向，绝不作为通过依据。
2. **统一预测与验收。** 接触、摩擦、PD饱和、整机运动、硬件边界、非足部地面净空和终端状态使用同一预测轨迹。新路径不使用“只缩放关节加速度”的旧回放来判定可行性。
3. **实测状态滚动求解。** 每次从原生q、v和真实上一帧关节命令重新开始；仅把上一次剩余命令作为初值，不把旧预测状态当作当前状态。每10个控制tick或接触标志变化时重规划，不冻结同一帧姿态0.4秒。
4. **实际命令审计。** 保存学生请求、教师序列、最终下发、实测状态及最新计划预测误差。新增独立审计按80步新模型重放每次被接受计划，检查当前观测、历史命令、触发时机、命令映射及其他127条轨迹。
5. **明确失败边界。** 没找到通过约束的计划时，停止该回合教师输出并标记学生回退。回退不是认证恢复、不是有效教师标签；本轮不自动蒸馏、不自动替换最佳策略。

候选末端：roll −0.25962 rad，pitch 0.15110 rad，角速度范数0.87592 rad/s，水平速度0.20678 m/s，最大关节速度0.96328 rad/s，竖直速度0.05662 m/s，支撑裕度0.05095 m，3足支撑。硬件与数值容差沿用原配置，没有降低任务判定。它仍接近部分终端边界，需要实际反馈检验。

离线修复耗时约213秒；在保存的真实原生查询状态上重新求解与独立验证耗时约7.81秒。当前适用于同步仿真中的离线/慢速教师研究，**未达到100 Hz实机实时控制要求**。

新作业上限为GPU0两小时、102400环境步，等前序真实进程退出且审计成功后启动。前序失败则停止队列，防止混用未确认结果。该实验选择已知TRAIN3及查询时刻，主要回答“这个真实状态能否接回来”，不代表通用因果风险门控。保持其他127例和击球前缀用于对照。

新模型仍不等价于PhysX全部碰撞、接触和电机实现；尚未证明连续稳定，也未证明覆盖原26个恢复失败。即使本次救回TRAIN3，还需要在其他失败状态上验证，并在有效纠正学习后单独关闭教师评估。
