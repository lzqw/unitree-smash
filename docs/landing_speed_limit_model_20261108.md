# 关节速度约束修正与持续恢复复测

2026年11月8日。本轮没有提高原生完整成功率，完成的是经过实测检验的预测模型修正：补上仿真关节速度约束的反作用，并再次检验原12条恢复候选。学生27/128、辅助候选28/128及未通过的隔离检查保持原记录。

## 为什么需要改模型

本机腿部配置`velocity_limit_sim=30 rad/s`，机械臂为`5 rad/s`；Isaac Lab把这一配置写入PhysX关节速度限制。与本机107.3系列匹配的官方文档说明，该限制由关节空间冲量执行。旧预测器计算隐式PD与足地冲量后只检查速度是否越限，缺少相应约束反作用。[Omni Physics 107.3关节文档](https://docs.omniverse.nvidia.com/kit/docs/omni_physics/107.3/dev_guide/joints/physx_joint_schema.html)

新内核联合求解：

\[
M(v^+-v)=\Delta t(S\tau-h)+J^Tp+S\ell,
\qquad |S^Tv^+|\leq v_{max}.
\]

其中`p`是满足单边接触和摩擦条件的足地冲量，`ℓ`是仿真关节速度约束反作用，`τ`仍受原电机力矩限制。完整质量矩阵使约束反作用同时影响机身、关节和足地支撑，不是单独裁剪关节速度。约束反作用与电机力矩分开记录，不能将此仿真机制当作真实电机额外具有的制动能力。

速度约束未激活时，程序保留旧求解路径逐项精确一致。激活时联合检查动量平衡、接触互补、摩擦及速度约束；未收敛就报告失败。该固定点模型不是PhysX有限迭代次序的精确复制，仍需实际响应校准。原物理参数、任务判定与接受阈值没有改变。

## 已运行的验证

6项独立力学测试通过：无约束激活时与旧模型精确相同；浮动基座解析反作用；饱和电机与约束冲量分离；无摩擦情形对照独立原始QP；摩擦、支撑和限速同时满足；错误速度限制被拒绝。

随后用8条原成功参考及4类失败案例的48个真实记录区间，输入相同的实测状态与实际下发目标，对比10毫秒、160物理子步的预测。两种模型均完成48个区间，30个区间激活了新增速度约束，计算约8.38秒。

| 一步误差 | 旧预测 | 新预测 |
|---|---:|---:|
| 每区间最大关节速度误差的中位数 | 0.01583 rad/s | 0.00788 rad/s |
| 最大关节速度误差 | 2.65341 rad/s | 0.70397 rad/s |
| 最大机身角速度误差 | 1.75610 rad/s | 0.33386 rad/s |
| 最大机身姿态误差 | 0.01331 rad | 0.00173 rad |

最大的改善位于机械臂`joint2`。例如TRAIN35第300步从2.653降至0.0268 rad/s。也有一个区间最大关节误差略增约1.07e-5 rad/s，不能声称每一项都改善。

按现有1毫秒头部接触力观测分组：43个未观测到头部对地受力的区间，最大关节速度误差由2.653降至0.1484 rad/s；另外5个有头部受力的区间，新模型最大误差仍为0.704 rad/s。它们是关联证据：当前预测器只处理足地响应，尚不含非足部和全部自碰撞响应。没有观测到头部力也不表示所有其他接触都不存在。

这些数据支持修正本轮速度模型，不代表完整恢复已经预测正确、模型覆盖全部状态或计算满足实时性。

## 12条原候选的结果

保持相同初态、相同参考选择、相同命令接口和约束，替换预测器后重新执行全部12条候选。旧版为11条速度越限、1条头部触地；新版全部转为头部触地，仍然0条完整模型解。TRAIN87候选从旧版2步推进到26—27步；另外三类推进到18—22步，但均未完成520步。

这说明速度模型的缺项确实改变了拒绝位置，却不是恢复失败的全部原因。不能将“更晚失败”报告为完整恢复收益。

## 成功参考的一个重要边界

复查已完成的原生头部接触力记录，并核对这些案例与新状态库的观测、动作逐项一致，确认选中的8条旧评分成功参考，在合格足端着地之后全部出现过头部对地受力。原评分未覆盖这些头部接触；保留原分数方便追溯，但不能把这些参考直接当成无非足部触地的教师。

例如TRAIN17首次着地后头部力出现在3.079秒、TRAIN35为3.047秒；四类失败也有相同问题。新增候选仍拒绝头部穿地，不通过允许头部支撑或修改评分来制造提升。此前“非足部净空未负”的几何检查并不否定接触：真实物理求解器可以把接触表面保持在接近零间隙，同时产生承载力。

当前已启动同四类实际状态的新一轮全剩余回合搜索，用修正后的速度模型调整动作；它仍从真实击球后状态出发，保留头部净空与完整稳定窗口。模型搜索有结果后，才考虑从地面执行其候选。尚未生成新的合格教师数据或关闭教师后的学生收益。
