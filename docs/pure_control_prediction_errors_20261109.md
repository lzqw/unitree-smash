# 纯控制落地：区分真实碰撞、数值失败与预测误差

2026-11-09。本轮没有新RL、BC或蒸馏，没有修改正在运行的原生控制器。原生最佳仍为5/128落地段通过；五例接管前均有头部接触，不能称为整回合无碰地。

## 一步预测在不同阶段的表现并不相同

本轮从已完成的V15原生运行中选取434个事件标记区间，覆盖释放、首次触地、支撑建立、支撑后200毫秒和1秒、首次非足部触地及干净末段。部分标签可对应同一物理区间，434不是独立回合数。

每次以真实q、v和上一命令为初态，执行当时实际下发的完整关节目标，使用160个物理子步推进10毫秒，再与该运行自己的下一原生状态比较。自由基座速度统一转到世界坐标，构型使用流形差值。没有传送原生机器人或修改控制命令。

结合逐物理步的地面与球网受力，单独分析无正值非足部地面力、无机器人触网力的区间。该筛选只用于事后诊断，不参与控制触发。

## 球网拒绝有真实接触证据

在没有非足部碰地的区间中，13条模型拒绝涉及球拍—球网碰撞。查回原生球网配对受力，这13条全部存在正值受力，峰值约44–5477 N。

因此，不应通过关闭球网检查或放宽穿透阈值让这些动作“可行”。这个一致性仅说明碰撞事件确实存在，不证明模型预测的精确时刻、净空或冲量与原生完全相同。

## 5个数值失败可以求出解，但解仍不等于准确恢复

没有非足部碰地和触网的63个首次触地区间中，5个在接触／关节约束迭代400次后未收敛，分别为5:312、71:300、95:304、99:304、107:313。

新增独立模型候选只在接触固定点迭代耗尽时，将上限增加到4000；原始已收敛路径不变，硬件、碰撞几何、摩擦、残差容差及动量检查不变。它没有进入现有原生作业。

五个区间全部获得数值返回，所需最大迭代次数1194–2553；但结果仍有明显问题：

- 与原生下一状态的线速度误差约0.61–0.79 m/s，角速度误差约2.55–3.57 rad/s。
- 70–133个子步激活关节止挡，最大止挡冲量约2.89–4.62 N·m·s。
- 其中两条预测路径仍违反非足部净空，最大模型穿透约3.87和6.08毫米。
- 另外15个本已正常收敛的对照区间，预测误差指标变化均为0。

因此，这次证明的是“400次不收敛不等于这个模型没有数值解”，而不是“五个落地状态已经可恢复”。增加求解预算没有消除冲击与关节约束响应差异，不能据此部署或生成专家标签。

## 对控制优化的影响

目前应区分三类问题：真实触网等动作不可接受；部分冲击状态的数值求解不足；以及已经收敛但与原生响应不符。三者不能统一归为“MPC求解失败”。

当前证据支持继续搜索不同落脚、缓冲和加载动作，重点避免依赖激烈关节止挡反作用的预测路径，同时保留实时反馈和原生完整执行检查。它不支持为了更多模型通过而放宽碰撞与执行器要求，也不支持等待完美PhysX复刻才继续控制实验。

六类新释放状态的全身序列搜索仍在运行，已完成948个粗候选，正在精细复核。GPU0的12＋118原生对照已推进到至少300控制步，后续58＋123与完整V15组合保持串行等待，输入未改动。上述运行中状态是本报告记录时点，不是最终成绩。
