# 从完整稳定模型动作出发，优化整段落地裕量

## 为什么改变优化层级

上一版V25在20毫秒候选评分中使用50毫秒匀速净空外推，三例均退化。V26改为接触动力学预测后，三例都恢复完整模型通过，但最低非足部净空只在TRAIN8从2.007毫米增至2.356毫米；TRAIN67略降，TRAIN96全部动作与状态不变。详细证据见[局部净空对照](pure_control_clearance_objective_20261109.md)。

因此，本轮直接优化完整恢复命令序列，以已经完成8秒且满足原稳定窗口的模型反馈作为初值。第一目标是继续完整稳定；只有在这一层成立后，才比较净空与运动代价。不会让局部净空奖励抵消碰撞或稳定失败。

## 本轮实现

- 初态仍为原生球分离记录8:272、67:269、96:268；q、v、上一命令及足端力与实际记录逐项核对。没有原生状态传送。
- 后续初始命令来自已经完成的模型反馈，不来自未来原生动作。将每个10毫秒命令保留为基准，再联合优化18关节的平滑修正，包括第一条恢复命令。
- 原关节、执行器、碰撞与稳定要求保持。每个候选使用160物理子步，一直计算到原8秒末或明确失败。
- 候选先按完整物理路径与原终点稳定筛选，再比较非足部最小净空、低净空累计代价和运动代价。10毫米是搜索偏好，不是新的成功阈值或已标定的误差界。
- 净空目标采样于10毫秒控制边界；碰撞路径仍在物理子步检查。不能将采样裕量当作连续时间或PhysX接触保证。

噪声相关性用于协调腿部伸展和全身动作，初期更关注冲击阶段；后续命令仍可调整。搜索标准差不是额外动作上限，也没有重新引入固定恢复前缀或0.08 rad修正限制。该方法是离线全轨迹优化，尚不构成实时全身MPC。
