# 落地接触语义与脚间碰撞预测：2026年11月8日

本报告接续[成功触地记录与26案例运行快照](landing_timed_impact_and_family_progress_20261108.md)。结论是：接触阈值不是当前唯一问题；成功恢复中的脚间碰撞也进入了足端力信号，而原预测器没有处理该相互作用。加入脚间接触后改善了部分一步预测，但最大撞地误差仍未解决，尚不能提升为可用MPC教师。

## 已完成的原生结果

冻结学生仍为27/128。TRAIN85完整时序参考与连续反馈的辅助运行再次得到28/128，原27个完整成功保留，新增TRAIN85；合格空中触球74，条件恢复35，数值故障0。这是辅助执行结果，不是学生学习收益，也不是新的在线MPC成绩。

本次原生运行 `native_timed85_impact_all128_20261108_02` 使用原物理参数、5 m/s任务标准和恢复窗口，耗时1259.668秒、0.349908 GPU小时、102400环境步。没有改变学生、教师或动作配置，只增加被动记录。

全128例的完整第一回合公开观测与下发动作，和上一辅助运行逐位一致。15个原生提前终止案例按真实第一回合长度比较，不强制补齐800步。13个控制边界的状态与力完全对齐，历史目标最大差异1.72e-7 rad，小于原容差。记录器透明性通过。

这不解决辅助运行相对于原学生的严格隔离问题：未介入案例46、82、125仍有轨迹差异。记录器与辅助父运行一致，不能代替控制器相对于原学生的隔离验收。历史28/128定高辅助、新TRAIN85辅助和TRAIN87实际状态重规划也不是同一策略，不相加、不合并成功集合。

## 从接触力语义到一个具体反例

用户对旧报告的纠正成立：`observed_foot_contact`来自足端法向合力范数的1 N接入、0.5 N保持门限，并非独立几何接触。旧37条差异只表示两种受力判据不同，不足以证明主要失稳根因。

新记录进一步显示，足端法向力还可能来自另一只脚，不能自动解释为地面支撑。在TRAIN85的物理帧46791（2.9244375秒）：

| 量 | 记录 |
|---|---:|
| 左前脚球面离地距离 | 0.0683444 m |
| 右前脚球面离地距离 | 0.0770884 m |
| 两前脚球面间距 | 8.89e-6 m |
| 左前脚法向合力 | [2082.85, 3159.51, -768.67] N |
| 右前脚法向合力 | [-2082.85, -3159.51, 768.67] N |
| 原观测接触标志 | [true, true, false, false] |

两脚仍高于地面，却同时被原观测标为接触。两力相反、方向与球心连线吻合，支持脚间碰撞解释；没有记录原生碰撞对ID，故不宣称已经直接读取到具体碰撞对。

2.88—3.00秒窗口共有1921帧：TRAIN85出现883个脚对间距小于1 mm的“脚对—帧”，其中274帧存在相反的水平法向力；TRAIN87两项均为0，最近脚对间距0.18735 m。1 mm仅用于事后统计，不是新增原生接触阈值。

这说明仅将力范数改成世界Z力或增加滞回，仍可能把内力当作承重。后续恢复控制应优先读取地面过滤的接触力，并将足地距离、相对速度作为独立一致性证据；实际接触、轻载可加载、可靠承重与卸载需要分开。当前实验没有修改历史评分或强行把原成绩重算为更高结果。原接触口径对着地时刻和稳定窗口的影响仍需单列审计。

## 已执行的候选模型改进

新增 `foot_pair_contact_step_v1.py`，在原浮动基座、位置PD、摩擦、关节速度与位置止挡的耦合求解中增加六个脚对的球形接触。脚间冲量在两刚体同一世界点上等大反向施加，不增加外部支撑力。原生材料记录给出脚间摩擦0.5、足地约0.65；通过接触坐标缩放表达不同摩擦圆锥，没有修改原PhysX材料。

候选只使用当前状态、原命令、原几何与材料，不使用下一帧力来决定动作。当前运行中的GPU控制器和已固定源码均未改动。

对两个案例全部3840个62.5微秒物理区间，从相同实测初态、使用相同实际命令独立预测：

| 指标 | 原模型 | 增加脚间接触 |
|---|---:|---:|
| TRAIN85关节速度最大误差的区间中位数 | 0.007851 rad/s | 0.003266 rad/s |
| TRAIN85最坏区间误差 | 41.9083 rad/s | 41.9083 rad/s |
| TRAIN85改善／变差区间数（差异>1e-6 rad/s） | — | 273／1 |
| TRAIN87中位数 | 0.00011081 rad/s | 不变 |
| 完成求解区间 | 3840/3840 | 3840/3840 |

物理帧46791的误差从1.4801降至0.2389 rad/s；帧47061从0.6567增至0.7886。最大撞地误差没有改善。TRAIN87在本窗口未落地，只能作为此窗口无接触情况下的回归对照，不能据此宣称其落地模型已验证。

几何法向Jacobian与独立有限差分最大差异1.40e-9；脚间接触对浮动基座的外部广义力系数残差2.37e-16，耦合动量方程残差2.15e-14。它们支持候选内部计算一致，不代表等价复现PhysX。

原模型在首次加载附近仍有两个大误差：帧47060为25.8247 rad/s，帧47086为41.9083 rad/s。实际首次大冲量发生时足球面下一帧仍略高于理想平面；当前一步模型与原生有限迭代接触求解的时序、速度更新还不一致。不可用人为增大摩擦或仅按关节加速度比例缩放掩盖差异。新脚间模型暂不晋升到在线MPC或专家标签。
