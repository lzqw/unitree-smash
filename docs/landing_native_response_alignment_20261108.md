# 实际命令下一步响应与名义轨迹偏离

2026年11月8日。本轮分析已经完成的避碰名义参考原生实验 `native_constrained_tracking_all128_20261108_02`。该候选旧评分27/128，TRAIN3最终翻倒，严格案例隔离审计失败。这里没有重跑或修改PhysX。

## 比较的是两个不同问题

新增审计程序分别计算：

1. **一步响应误差**：每次从记录的实际q、v、接触、上一条命令出发，执行实际最终下发的位置目标，用160子步预测下一控制步，再与实际下一状态比较。
2. **计划偏离**：比较当时生效的名义预测与实际轨迹。若存在在线重规划，切换点使用上一物理区间生效的计划，不用新查询状态掩盖上一步误差。

一步分析不会把理想力矩当作实际命令，检查最终归一化动作与解码关节目标一致、命令历史连续。计划偏离还包含状态反馈导致的后续命令变化，不能全部称为单步动力学误差。

检查原生控制步280至450的171个转换，均完成数值预测，没有髋部规划边界拒绝。**完成预测不等于路径有效**：部分步已记录模型非足部净空违反，不能被称为可行恢复动作。

误差并不均匀：

- 305步发生足端支撑集合变化，最大关节速度一步误差约1.333 rad/s，机身角速度误差0.0437 rad/s。接触标志此步一致，不能靠标志一致认定触地响应已准确复现。
- 323至345步有14个足标志不一致，主要涉及RR，随后涉及FL和RL；这23步的机身角速度误差最大只有约0.00395 rad/s。仅凭这些标志不同不足以认定它们造成后续翻倒。
- 346至386步没有记录足标志不一致，但机器人仍在偏离名义轨迹。
- 387步起，模型预测记录RR_calf地面净空违反；388步机身角速度一步误差达到约1.058 rad/s，415步最大关节速度误差约4.440 rad/s。当前预测器没有非足部碰撞响应，不能用其已穿入地面的自由运动解释完整实际碰撞过程。

原生第一项旧非足部事件记录在physics frame 62896，配对接触包含RR_thigh约950.24 N；同帧RR_calf法向合力为零。模型净空事件与实际碰撞部件并不完全相同，不能把模型RR_calf越界当作已经证实的原生RR_calf触地。该窗口内也不能据此唯一归因到某个PD增益。

接触比较已另外按模型法向力重建1/0.5 N滞回，而非只比较正冲量标志。即使判据对齐，接触时序、碰撞顺应性和传感采样仍不同。模型最后子步法向力与原生采样瞬时力不等于整个区间冲量，不能把某一时刻20 N对0 N直接称为多了一只虚假承重脚。
