# TRAIN87完整模型恢复与原生验证

2026年11月8日。本轮出现一个值得进行原生验证的完整模型候选：TRAIN87从真实击球后2.8秒状态开始，完成到原8秒回合末的520个控制步，并保持末端连续稳定2.58秒。它不是原生成功，也不是学生已学会的结果。

## 模型结果

前一轮前脚前移6厘米、下伸2.5厘米的初始化，在123步后头部触地。本轮保持原模型中的前0.35秒完全一致，从此后优化全身关节目标过渡，同时保留根据当前状态调整动作的姿态与轨迹反馈。没有开启新增关节制动，没有更改真实电机增益、摩擦、质量、关节界或任务判定。

两代搜索后得到完整候选，包含48个粗预测和8个精细预测，随后以160物理子步／控制步独立重放整段520步。状态、速度、接触与下发目标逐项精确一致，总计算约358.21秒。

## 实际反馈接口

新增通用案例执行入口，将原生q、v、实际接触和上一条实际下发命令送入同一反馈政策，不重放理想关节状态，也不传送机器人。名义预测仅作误差对照；正式动作仍经原float32归一化位置接口下发。其他环境原样保留当前学生动作，选中环境真实终止后也不把旧恢复计划施加到重置后的回合。

CPU接口重放覆盖原800步时钟及520条恢复命令。最大目标映射误差1.80×10⁻⁷ rad，原查询匹配通过；在相同名义时刻改变机身姿态后，目标变化0.01489 rad，说明没有把反馈退化为固定动画重放。名义轨迹保持不可变。该检查验证接口，不验证PhysX恢复。
