## 解释

这两项结果说明：

- 当前主要失败不是简单的摆动足落点偏移不足；
- 把腿目标拉向默认姿态也不能单独阻止前腿/身体后续塌陷；
- QP 的模型可行和最终 PhysX 中形成持续承重之间仍有明显差距。

因此不再继续扫描 capture gain、leg blend 或相近的姿态增益。下一步应直接记录并校准：

```text
QP总力矩
  -> 位置目标
  -> 实际PD力矩/限幅
  -> 实际关节与足端运动
  -> 足端受力、质心速度、非足部接触
```

只有确认实际命令能产生预期支撑响应后，才值得继续调整 MPC 代价；否则优化器只是在错误执行模型上寻找更多“可行”解。
