# 持续支撑轨迹反馈：模型对照从1/13到5/13

2026年11月8日。**新增的位置／速度／姿态轨迹反馈救回了4个此前失败的小扰动模型对照，名义轨迹完全保持。但8个对照仍失败，尚未运行此反馈版本的Isaac原生评测，不能更新27/128学生基线或称为稳定教师。**

## 本轮实际改动

上一轮精细模型中，成功的全身恢复参考只在精确初态通过，12个单轴小扰动均失败。原姿态反馈主要朝竖直姿态纠正，没有直接跟踪可行参考中的根位置与速度。

本轮在原全身参考上增加受限反馈：由当前状态与计划参考的根位置、世界线速度、姿态和世界角速度偏差，计算期望的小幅根位移，再使用**当前有支撑的脚**的雅可比求腿部目标修正。未接触足不加入支撑方程，不添加虚构外力；第一条命令保持前一实际目标。机械臂仍沿原参考执行，最终使用原位置目标和伺服。

参考来自已保存的可行模型规划，不读取未来原生状态。平移修正上限2.5厘米、转角修正上限0.04 rad、单关节附加目标上限0.08 rad；这些只是候选控制参数，不是已验证安全界。原力矩、关节速度、关节位置、非足部净空及终端支撑判定保持。

该模块是**候选反馈执行层**，可用于后续MPC的反馈延续；本轮没有新增在线动作序列优化器，也没有完成鲁棒MPC证明。

## 已运行结果

13个固定对照均使用160子步精细动力学，预测tick280至原8秒结束。4个CPU工作进程，耗时237.78秒，无预算过期。名义520步的q/v/目标与原保存轨迹最大差异为0，原3.76秒末段稳定窗口保持。

| 新救回的模型对照 | 原参考结果 | 新反馈末段稳定窗口 |
|---|---|---:|
| 世界X轴姿态−0.5° | 第313控制步后触地违规 | 3.35秒 |
| 世界X线速度＋0.02 m/s | 第153控制步后触地违规 | 3.72秒 |

| 世界X角速度−0.02 rad/s | 第328控制步后触地违规 | 3.25秒 |

所有步数均相对tick280。新增4个完整模型可行轨迹，加上名义状态，共5/13。**这些是确定性单轴测试，不是随机成功率，也不能作为原生专家标签。**

剩余8个失败包括5个头部触地、2个右前髋触地、1个实际关节位置越限。其中5个对照的失效更早；例如世界Y轴姿态＋0.5°从原第136步非足部触地，变成第101步关节越限。命令目标限幅并不保证动态状态永不越限，不能用通过的4例掩盖这一退化。

由此可确认：全程状态反馈能扩大部分可恢复范围，但当前基于运动学的修正还不能保证动力学和接触约束，不能直接全面替换原控制器。下一步要把实际跟踪误差、约束余量和重规划连接起来，并验证原生响应。
