## 本轮优化针对什么

前一隐式QP约束10 ms区间末端，在更细的隐式PD积分中，部分命令在区间中间违反摩擦、关节速度或力矩条件。只提高预测积分步数会发现更多错误，却不会主动寻找新命令。

新增 `IntervalCommandSupportQP` 直接优化18维实际关节位置目标，将每个10 ms区间拆为16个隐式PD子步，并把所有子步约束压缩到同一个QP中：

1. 保留加载机械臂和球拍的全身质量、偏置项、接触雅可比；每个区间内冻结这些系数。
2. 同时约束各子步的原关节范围、速度、力矩、非负法向力和摩擦锥。
3. 机械臂目标限速从实际上一条下发命令计算；保留原10 rad/s目标变化率和5 rad/s物理关节速度，两者不混同。
4. 每个子步加入原任务0.12 m根节点高度界，求解后再用独立隐式积分和非线性构型积分复核。
5. 控制与终端复核共用相同的命令预测路径；连续参考、实时支撑反馈及每tick重新求解保持。

这仍是**逐阶段QP滚动**，尚未联合优化整个0.4 s恢复序列。模型限定于整个区间未饱和的驱动分支和固定接触；不等价于PhysX碰撞／隐式驱动求解器，也不提供稳定性保证。预测接触提议仍需真实执行验证。
