## 新姿态反馈候选及已完成检查

[控制模块](../scripts/terminal_attitude_feedback_v1.py)利用实际支撑足的雅可比，求小幅腿部目标修正：

```text
当前机身滚转／俯仰误差与角速度
  → 有界的虚拟机身旋转修正
  → J_leg · Δq + J_root · Δθ ≈ 0
  → 将Δq加入原终端腿部位置目标
  → 原限幅和真实PD执行接口
```

这不是直接施加虚拟外力。接触集合只取当前状态，不把离地脚假定为承重脚。
前80步规划前缀不变、机械臂目标不变；没有支撑足时原样通过。
初版参数为姿态比例0.15、角速度系数0.02秒、单关节目标修正上限0.04 rad，0.2秒渐入。
原电机增益、力矩、速度、质量、几何和正式要求均不改变。

在真实第620步状态上做加载模型的有限差分检查：虚拟机身旋转引起的支撑足位移范数从0.017758 m降至0.001309 m。
这是核对雅可比修正方向与坐标的一项运动学证据，**不是实测足端跟踪误差或实际恢复收益**。
同时检查了机械臂目标不变、原输入状态不被修改、前缀关闭门控及无接触时原样通过。
