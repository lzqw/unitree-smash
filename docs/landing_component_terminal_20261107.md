## 补充闭环终端试验：平衡参考还不等于稳定姿态

将两个旧候选各自的末端静态平衡目标固定，比较立即切换及10/20/40步过渡，共8组模型试验。合法延续15—23步后均关节位置越界；最后合法状态中最接近下限的都是接口索引8的小腿关节，且速度仍朝屈曲方向。因而不能把之前失败只归因于“每步重算平衡参考导致参考漂移”。

再加入围绕固定末端构型的腿部姿态反馈：目标增加`k*(q_ref-q)`，以及小幅速度项。仅改变实际位置请求，物理PD、电机能力、位置限位和动力学预测均不变。模型比较`k∈{0.25,0.5,1,2}`、速度系数`{0,0.5}`，共16组。

其中5组完成160步（1.6秒）且无路径约束违规，但最长运动学稳定窗口仅0.35—0.47秒，末端滚转约−16.6°至−18.1°，仍未达到原任务恢复条件。其余候选较早失败。所有结果仍是模型测试，不得标为专家示范；也没有据此更改实际执行器增益。该结果支持下一步联合改进恢复终点构型与反馈，不能仅依赖静态重力平衡或低末端速度。
