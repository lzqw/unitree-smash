# 恢复终态的全身收敛与原生执行诊断（2026-11-07）

本轮延续 `eab4d78` 的完整地面几何约束序列优化。新增证据表明：**0.4秒末机身姿态与速度通过检查，仍不足以说明机器人能够继续稳定支撑。**当前没有新的原生成功率提升，也没有新增可供学生正向模仿的恢复示范。

本轮已执行CPU模型续段搜索、全身关节速度目标对照及11项测试；原生执行诊断已排队，尚未运行。紧凑数值、证据哈希和队列快照见[配套JSON](landing_terminal_settling_and_native_queue_20261107.json)。未更改5 m/s任务、物理参数、关节限制或正式恢复判定。

## 1. 为什么原先通过的终态仍不能当作稳定恢复

上轮TRAIN15候选通过0.4秒模型轨迹的动力学、执行接口、地面几何及原终端风险检查。但检查其完整速度状态发现：

| 量 | 0.4秒末模型值 |
|---|---:|
| 机身角速度范数 | 0.01483 rad/s |
| 腿部最大关节速度 | **11.92488 rad/s** |
| 机械臂最大关节速度 | **2.83814 rad/s** |
| 机身局部竖直速度 | 0.10842 m/s |

保持末帧命令再预测10 ms，机身角速度分量由约 `[0.008,-0.011,-0.006]` 变为 `[-0.451,0.345,0.047]` rad/s。这是同一近似模型内的结果，尚不是PhysX测量；它揭示了原终端指标可能接受一个短暂经过低机身角速度的状态，而非已经充分消散内部运动的状态。

随后从这一**预测终态**分别用“保持末命令”和“跟随实测关节姿态”两种初值搜索后续0.4秒支撑，每种最多12次任务优化和8次可行性修复。两者都没有找到通过全部检查的续段：

- 保持末命令：优化后机身终态指标虽通过，仍有约3.05 mm地面穿透、0.070 N摩擦约束违反，以及其他执行限制残差。
- 姿态初值：局部任务QP报告不可行，后续修复仍残留约274 mm地面穿透等明显违反。

因此，本轮两种初值的已验证续段均为0秒。**有限搜索失败不证明状态物理上不可恢复**；但原先的0.4秒通过不能再被描述为持续稳定的落地教师。

## 2. 已运行的优化：同时抑制腿和机械臂的残余速度

新增过程隔离的实验，在局部QP和非线性轨迹评价中同时加入18个关节的速度二次代价，权重2；沿途和终端使用一致权重。原始模型、限制、地面几何与验收容差均保持不变。未修改正在运行及排队原生实验所锁定的求解器文件。

六个真实记录查询状态均进行了搜索，结果如下。表中的终态速度是各次最终候选的预测值，**拒绝的候选没有进入原生执行**。

|---|---:|---:|---:|---|
| 2 | 0.00688 | 0.00305 | 0 | 通过，原有模型可行案例 |
| 3 | 0.38334 | 0.21499 | 0.00001793 | 拒绝 |
| 15 | 0.17187 | 0.15069 | 0.00000372 | 拒绝 |

本轮为1/6模型验收通过、**0个新增通过**。TRAIN15的内部运动明显减小，但地面违反仍超过原1微米数值容差，不能为提升通过率而放松。TRAIN3、18、65的机身终端风险指标也通过，但几何约束尚未通过；TRAIN57仍有较大物理违反。

这支持继续把全身速度收敛纳入优化，却不能宣布该权重已解决落地。下一步应在保持碰撞和执行限制的同时找到可继续支撑的终态，检查更长续段与实际反馈，而非仅把机身末帧角速度压低。

原始结果中的 `newly_model_feasible` 是继承的历史来源标志，不代表本轮通过；本报告仅依据本轮 `accepted` 统计。

## 3. 已准备的原生诊断及其边界

新入口从地面执行原128例，保持完整8秒回合。仅在TRAIN15第690控制步，对实际状态、接触、公开观测和上一条真实下发命令与归档查询逐项匹配；匹配失败即拒绝执行候选。匹配后执行上轮已经通过模型检查的40步命令，记录预测和PhysX实际状态的差异。新速度目标下未通过的TRAIN15候选不用于此作业。

40步后返回原学生，并按真实上一条指令维持机械臂10 rad/s的命令连续性；其余127例不覆盖动作。记录覆盖计划执行及后续回合，包括足端力、关节与根节点状态、接触变化、最终命令、首次非足部接触和完整结果。检查命令一致与预测准确分别报告，不能由前者推断后者。

**这是按案例和时刻触发的模型响应诊断，不是面向未知状态的触发器，也不是已经实现的持续反馈MPC。**TRAIN15原本没有合格空中拍线触球，球侧也不合格；即使它恢复改善，也不能直接给当前完整成功增加一个案例。选择它是因为它是目前新增的几何约束模型候选，用于检验计算结果能否实际执行。

队列状态为等待已有GPU对照和精确透传作业结束；独立生成的入口与108个依赖文件已锁定哈希，不会修改在运行的评估入口。GPU0作业限1800秒、102400环境控制步，无自动策略晋升、无自动专家标签。
