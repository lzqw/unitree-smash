# 状态驱动落地 MPC 候选

## 目标

当前候选不从历史参考库检索轨迹，也不根据 TRAIN 编号或失败名单选择动作。每个恢复控制 tick 都从实际全身状态、上一条实际命令和当前足地接触重新生成候选目标。

控制流程为：

```text
当前状态
  -> 状态派生的名义、阻尼、混合三个目标
  -> 耦合位置/PD全身QP
  -> 两个控制步的原生执行器与碰撞预测
  -> 选择风险最低的第一条命令
  -> 下一个tick重新计算
```

候选目标只是求解初值，不是动作库。若三个候选都不可行，控制器保持上一条已通过接口的命令并施加速度阻尼，等待下一 tick 从新状态重新求解；该保持动作仍标记为未经认证。

## 约束与边界

- 使用原关节范围、速度、力矩、摩擦、网球网和非足部几何约束；不增加外力，不删除碰撞，不传送状态。
- 仍通过原生位置 PD 接口输出完整 18 维目标。
- 当前实现是候选式短时域滚动 MPC，不是实时非线性全身 MPC 证书。
- 当前尚未进行原生 GPU 评估，不能把静态入口检查或模型候选通过当作落地成功。
