- **TRAIN58**：与V14在tick442之前的命令和状态相同。tick442开始执行新恢复参考，首个命令最大差0.458315 rad；下一控制采样出现运动差异。V14在5.116375秒记录右后小腿触地；本轮接管后所有非足部地面受力均为0，末段连续稳定1.42秒至回合结束。
- **TRAIN123**：首次新命令在tick409，最大差0.063705 rad；下一采样出现运动差异。V14在4.797秒记录左后大腿触地；本轮接管后所有非足部地面受力均为0，末段连续稳定1.14秒至回合结束。运行时按当前状态匹配，匹配分数0.69635，并非按TRAIN编号或固定秒数接管。

这些是完整原生执行证据，比模型可行率更直接；但仍是固定开发案例，尚未证明扰动覆盖或实时控制能力。当前实现是模型参考、局部候选预测与连续反馈的组合，不能称为已经完成全局在线序列MPC。

## TRAIN126高精度复核的新证据

两项“状态驱动持续支撑”模型复核均已完成：候选评分分别使用16和160子步，而实际执行模型均为160子步。两者都从同一原生记录初态126:272出发，完成528步至8秒，tick576转入支撑，末段模型稳定2.25秒。

但两条轨迹并不相同：tick361首次出现命令差异，最大关节目标差0.565048 rad；全程q坐标最大差0.027588，广义速度最大差3.523302。q和v包含混合坐标，不能把这些汇总直接解释成一个机身位置或角速度误差。转换后最大命令差降为0.008760 rad。结果一致不等于预测精度等价。

后续四项对照已全部结束且来源哈希复核通过。粗、细两种评分下，“等参考结束再支撑”均在tick680右后小腿触地；“状态驱动支撑”均完成528步。每个相同精度的配对在转换前304步的命令、q和v完全相同，tick576首次改变命令后产生状态差异。这支持该具体状态下的支撑交接收益，不能推广为所有失败的唯一原因。新43条库的原生V23实验已排队，TRAIN126暂不计入原生成绩，也不标为专家示范。
