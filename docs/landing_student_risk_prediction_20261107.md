# 原学生持续支撑风险：按案例隔离的离线预测

2026-11-07。不是新的控制成绩，没有安装在线门控，没有导出教师或学生权重。GPU0的完整18关节区间对照仍在运行。

## 目的与输入

全128例持续教师曾将原27个成功降到20个；仅按已触球、触地阶段启用，不能区分学生原本能够恢复的状态。本项检查已有真实轨迹能否支持更有区分力的风险预测，不预先认定教师能够救援。

输入为已经完成的原27/128冻结学生运行，实际执行命令与原始观测均有记录。使用当前本体状态、100 ms前本体历史、当前学生最终关节命令和此前执行命令，共158维。排除案例编号、回合时钟、来球/目标字段和最终结果。标签由原始非足部接触力事件产生：学生保持原策略执行，随后0.8秒是否首次出现非足部接触。

只采集因果观测到空中触球、继而建立支撑后的状态；已出现非足部接触的状态排除。每50 ms采样一次，训练标签不能确定的回合尾部窗口不作为负样本。110个案例产生6607个可标注窗口，其中765个正样本；报警检查另覆盖7519个全部合格阶段的事前状态，包含无事件回合尾部。

## 隔离与方法

按案例编号模5作预先固定的五折划分；每折一个集合验证、下一个集合校准、其余拟合。整条案例不跨这三个集合。归一化只在拟合集计算，模型为案例/类别加权、L2系数0.01的逻辑回归，没有超参数扫描。阈值取校准集中未出现非足部接触案例的全阶段最大分数之上。这是保守校准规则，不是安全证明，分数也未标定成真实失败概率。

编号只用于离线分组，不能在未来运行时按TRAIN编号挑选五个模型。当前没有输出可部署模型；真正部署仍需统一模型及独立轨迹验证。

## 结果

| 指标 | 结果 |
|---|---:|
| 留出案例窗口AUC | 0.99085 |
| 正样本窗口召回 | 68.10% |
| 负样本窗口误报 | 1.10% |
| 原22个球侧合格、非足部触地失败提前0.2–0.8秒报警 | **21/22** |
| 原27个成功案例至少出现一次误报 | **3/27** |

21例预警提前量为0.200–0.785秒，中位数0.545秒。TRAIN9虽然出现报警，但未达到至少200 ms提前量。三个旧成功误报为TRAIN32、35、52，分别在3.10、3.05、3.05秒首次出现；每例仅1–2个50 ms采样点，尚未测试时间滤波，不能据此声称连续确认即可消除误报而不损失救援时间。

全阶段校准比只看完整0.8秒标签窗口更严格：初版曾得到22/22预警，补入回合尾部报警检查后为21/22。最终以这里的全阶段结果为准，两份本地结果都保留。首次运行仅在JSON序列化阶段失败，日志也保留。

## 对下一步的影响

此结果支持继续研究“预测学生风险后选择纠正”，而不是把阶段门控等同于危险判定。但不能直接用这个数字替换完整成功率，也不能拿历史轨迹上的报警遮罩推算加教师后会成功多少。干预一旦改变状态，后续轨迹和风险模型适用范围都可能改变。

当前仍缺少两项：教师在这些报警状态上是否确实有可执行的救援动作；改变轨迹后风险预测能否保持可靠。另有4个球侧合格恢复失败没有非足部触地，此分类器不覆盖稳定窗口不足。它也不是对学生后续策略与接触动力学的完整滚动仿真。

不修改正在运行的原生对照。待控制收益结果完成后，再将风险预测、教师可行性及原样通过学生命令合并为明确候选，并单独进行完整回合验证。当前学生基线仍为27/128，正式G07验收仍未通过。
