## 对后续MPC优化的意义

1. **先保留能持续支撑的反馈后段。** 这次较便宜的连续反馈救回了一个真实失败，而上一轮在线MPC V2在613/800步超时且没有完整结果。应把反馈作为滚动规划的候选延续，检验从当前状态到稳定窗口的整段可行性；短时可行后任意保持首帧仍不足够。
2. **机械臂速度余量对照继续。** 当前GPU0运行的是独立版本，加入已在高分辨率模型中检查过的微小参考修正。运行中的结果不能计入成绩，也不修改本次成功版本。
3. **滚动MPC保留可诊断的拒绝及回退。** 后续已排队的候选组合运行包含原反馈与机械臂余量反馈，并保存物理子步接触记录、未完成前缀和失败计划，避免再次超时后丢失关键状态。
4. **隔离问题先解决，再提升数据等级。** 对TRAIN125需要真正的无介入对照；现有完整成功可保留为待核实样本，不能绕过失败审计批量蒸馏。

这些控制器目前仍针对已知TRAIN3和固定时钟做诊断，既不是通用风险触发，也不是覆盖所有26个球侧合格恢复失败的教师。
