# TRAIN125偏离定位：真实机器人状态与相对球观测分开

2026年11月8日北京时间。依据已完成原生记录的离线复查；[紧凑证据](landing_physical_divergence_boundary_20261108.json)。本次没有新增完整原生结果。

## 新确认的证据

对两版持续反馈、记录版滚动MPC和无实际动作修改负对照，重新读取原128例中的TRAIN125。
同时比较100 Hz公开观测／实际下发动作，以及50 Hz真实机体位姿／球世界坐标。33项来源哈希重新核对一致。

| 运行 | 首次公开观测不同 | 首次50 Hz机体位姿不同 | 球世界坐标与基线 |
|---|---:|---:|---|
| 持续终端反馈 | 第567步 | 第568步 | 全部400帧相同 |
| 机械臂裕量版本 | 第567步 | 第568步 | 全部400帧相同 |
| 记录版滚动MPC（仅执行一个教师控制步） | 无 | 无 | 全部相同 |
| 仅计算教师建议、不执行 | 无 | 无 | 全部相同 |

两版持续反馈在第567步之前的TRAIN125下发动作完全相同。第567步首先记录到机器人速度、姿态、关节状态变化，随后当步学生动作才不同；观测历史和上一动作在这一刻仍一致。

**因此，不能把公开观测中的球字段差异直接解释成球的真实飞行轨迹变化。**当前球观测依赖机器人参考系；机体运动不同，可以使相对球观测不同，而球世界坐标仍相同。
50 Hz位姿还确认了偏离不是仅存在于公开观测打包中。不过，它不能分辨5.66—5.67秒内第一个不同的物理子步。

## 仍未确定的原因

这份证据没有证明跨环境碰撞、共享控制内存或GPU求解顺序中的任何一项是根因。
源码配置确实开启了环境ID碰撞隔离，且原精度准入中有隔离检查；这些不能替代本次动态轨迹上的隔离证据。
原有严格审计继续保留，未介入环境容差没有放宽，两版28/128仍不能自动成为有效专家数据。

## 已增加的定位程序

[离线比较程序](../scripts/audit_physical_lane_divergence_v1.py)把物理位姿与公开观测分开比较。
[逐物理步记录器](../scripts/native_isolation_microtrace_v1.py)可以同时记录TRAIN3和TRAIN125在5.60—5.75秒附近的2401个物理帧，区分：

- 环境请求的关节目标、articulation目标，以及实际提交PhysX的目标／附加力矩缓冲；
- 外力缓冲及其启用、坐标系和作用点设置；
- 实际关节与根状态、足端法向力、接触标志、球世界状态。

这些命令／缓冲记录不是实际电机力矩测量，法向力也不提供碰撞对手或切向力。
记录器每次调用原观测钩子一次，不改控制和物理；3项CPU测试验证了目标缓冲分离、重复帧、缺帧不冒充完整窗口和钩子生命周期。这些测试不证明原生物理隔离。

[准备程序](../scripts/prepare_native_isolation_microtrace_v1.py)已生成持续反馈和负对照的独立记录入口，原控制保持不变。新记录入口尚未启动，也未插入正在运行的实验。
