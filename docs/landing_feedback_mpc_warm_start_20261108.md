## 已进入求解器的改动

`FrictionalFeedbackSeedRecoveryV3`在每次调用时接收当前测量状态、实际命令历史与因果控制时钟：

1. 用持续反馈从当前状态生成80步候选命令；预测中保留整机耦合、接触与原执行器模型。
2. 任一路径约束失败则丢弃该初值；路径通过后仍独立检查原末端要求。
3. 候选通过后，交给原V2求解器再次验收；候选被拒绝时继续使用原平移计划和原修复路径。
4. 生成初值不等于允许执行，最终结果仍由原求解器的非线性复核决定。

在上述第478步实际查询上，新版完整调用两次分别用时14.85、14.92秒，均通过，末端结果一致。此前V2从平移初值修复该查询约498.78秒。这是该已知查询的墙钟对照，运行负载与初始序列不同，不能扩展成普遍加速比，更不满足100Hz实时控制要求。

新版目前只完成CPU模型求解，尚未替换正在运行的原生V2或两项排队反馈对照。它使用当前案例的相位条件参考，不是通用风险教师；第473步的失败仍要求改进状态反馈/约束处理，不能无差别复制当前候选。
